AlpeHuez v0.7.0

A workspace browser for Helloxiaolaodi. It combines the portal dashboard, vertical browser tabs, persistent sessions, local achievements, and the developer console in one desktop shell.

v0.7.0 Update Notes

  • Summon fix: restoring AlpeHuez from the tray reliably shows the window again — no more restart to bring the interface back.
  • In-app new tabs: target="_blank" links inside open webpages open a new tab in AlpeHuez instead of the external browser.
  • Notes workspace: a new left-rail Notes view — searchable journal list by date, editor with live Markdown preview, auto-save, delete, and export.
  • Code snippets in Daily Notes now wrap long lines instead of scrolling horizontally.
  • Developer Panel: Software tab added to the embedded panel tools.
