AlpeHuez v0.3.0

A workspace browser for Helloxiaolaodi. It combines the portal dashboard, vertical browser tabs, persistent sessions, local achievements, and the developer console in one desktop shell.

v0.3.0 Update Notes

  • Unified AlpeHuez workspace shell: Portal, My Files, Dev Panel, Achievements, and About sit in the Activity Bar with contextual sidebar panels.
  • Zen-style vertical tabs replace the crowded top tab strip; link cards, GitHub, cnblogs, and Ko-fi open inside AlpeHuez WebViews.
  • Internal WebViews add an auto-hiding command bar with back navigation and fullscreen/exit-fullscreen controls, plus persistent sessions and ad blocking injection.
  • The Portal sidebar is auto-hidden with an edge handle and keeps its page tabs in the sidebar instead of the content area.
  • My Files uses an auto-hidden sidebar with collapsible main folders, and the report pages are password-gated without committed secrets.
  • Dev Panel requires a password on every entry with no remembered access, and its Deploy/default screens no longer trigger transient popups.
  • Launch mode configures internal AlpeHuez startup or an external browser selected from a dropdown.
  • Interface config adds local background upload, background blur, shortcut settings, feedback, Ko-fi, WeChat QR support, and language selection.
  • Dark mode uses the blurred AlpeHuez space background, search dropdown width is restored, and the timeline row aligns with the search box.
  • Glassmorphism styling, foldable tag groups, and the preserved light SaaS palette complete the v0.2.0 visual refresh.
