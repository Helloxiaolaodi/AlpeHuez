# AlpeHuez v0.3.0 UI 融合设计（AFFiNE × Homepage × Homarr）

> 状态：已获用户批准（2026-08-17）。用户指令：全部功能纳入 v0.3.0，重建发布但**不立即归档**。

## 背景

v0.3.0 已实现多工作台（车队模式：主将 GC Contender + 4 名副将）+ 玻璃拟态视觉。本 spec 将三款开源 UI 优等生的设计哲学融入：

- **Homepage (gethomepage)**：高密度服务网格 + 状态监控 + Glance Bar
- **Homarr**：Bento 便当盒网格 + 规整瀑布流
- **AFFiNE**：块级悬停交互 + 空间拆分视图（Peek）

## 设计原则

1. **配置驱动**：JSON 为唯一数据源（`workspace_links.links_json`），拖拽排版为 v0.4.0 增强，不在本版本范围。
2. **容器统一**：所有卡片/微件使用统一 `.alpehuez-widget` 玻璃容器类。
3. **字体层级**：主标题 `font-weight: 600`，辅助信息 `font-weight: 400` + `opacity: 0.5`，抛弃过多颜色区分。
4. **向后兼容**：所有新增链接字段可选，旧数据无字段时行为不变。

## 功能需求

### F1: 工作台标签栏移至顶端

**现状**：`#workspaceTabs` 是 `.app-shell`（`display: flex` 行方向）的首个子元素，渲染为**左侧竖条**。

**目标**：5 个工作台标签（主将/平路副将/山地副将/古典赛副将/带冲手）水平排列在**窗口顶端**，Chrome 标签栏风格。

**实现**：
- `.app-shell` 改 `flex-direction: column`
- 新增 `.app-body` 包裹 `.action-rail` + `.tab-sidebar` + `main.workspace`，样式 `display: flex; flex: 1; min-height: 0`
- `#workspaceTabs` 保持为 `.app-shell` 首个子元素 → 自动成为全宽顶栏
- `.workspace-tabs` 现有 CSS（`border-bottom`、`background: var(--panel)`）已适配顶栏形态，微调即可

**验证**：启动 App，5 个工作台标签水平显示在窗口顶部，切换正常。

### F2: 状态指示灯（队车通讯电台）

**数据**：`workspace_links.links_json` 中每条链接对象加可选字段 `monitor: true`（默认 false，探测目标默认用链接 URL）。

**后端**：新模块 `src-tauri/src/status.rs`
- 后台线程，每 30s 遍历所有工作台链接中 `monitor: true` 的链接
- HTTP HEAD 请求，超时 3s，用 `ureq`（新增依赖，轻量阻塞式，适合后台线程）
- 结果缓存 `HashMap<url, {online, latency_ms}>`
- 通过 `service-status-update` 事件推送全量状态

**前端**：
- 卡片右下角 6px 状态点：绿=在线、红=掉线、灰=未监控/未知
- 在线时冰雪蓝（`#B1E3FF`）呼吸光晕动画
- 监听 `service-status-update` 事件更新

**验证**：标记 2 个链接 `monitor: true`（一个可达、一个不可达），30s 内卡片出现绿/红状态点。

### F3: Bento 网格（战术板）

**数据**：链接对象加可选字段 `span: [cols, rows]`（默认 `[1,1]`）。

**实现**：
- Portal 内容区改 `grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))`
- 卡片按 `span` 设置 `grid-column: span N; grid-row: span M`
- 卡片统一 `.alpehuez-widget` 类：`background: var(--glass-bg)`、`backdrop-filter: blur(16px)`、`border: 1px solid var(--glass-border)`、`border-radius: 12px`、hover 时暖麦色（`#FFE0AE`）边框高亮

**验证**：给一条链接设 `"span": [2,1]`，渲染为宽卡片。

### F4: Glance Bar

**实现**：VeloMeter 胶囊升级——背景改 `linear-gradient(135deg, #B1E3FF, #FFE0AE)` 微弱渐变，与搜索框平行（已在 topbar，保持位置）。

**验证**：顶部栏 VeloMeter 胶囊显示冰雪蓝→暖麦色渐变背景，CPU/RAM 实时跳动。

### F5: 块级悬停（AFFiNE 借鉴）

**实现**：Portal 侧边栏分类/链接项、文件树项：默认纯文字，hover 时浮现操作图标（编辑/复制/删除）。CSS `opacity: 0` → hover `opacity: 1` 过渡。

**验证**：鼠标悬停侧边栏项，操作图标淡入。

### F6: Peek View（补给递送）

**数据**：链接对象加可选字段 `peek: true`（默认 false）；或 Ctrl+点击任意链接。

**实现**：
- 触发时调用现有 `open_internal_page`，`width=400`、`x=窗口宽-400`、`y=0`、`height=窗口高` → 右侧窄子 WebView
- 前端 Peek 面板容器（毛玻璃），内含子 WebView，带关闭按钮
- 复用现有 `browser-load-started/finished` 事件显示加载态

**验证**：Ctrl+点击链接，右侧滑出 400px 毛玻璃面板加载网页，主线不中断。

### F7: 技师面板 JSON 编辑器

**实现**：开发者面板加"工作台链接 JSON"视图：
- textarea 编辑当前工作台 `workspace_links` 原始 JSON
- 保存前校验 JSON 合法性，合法则调用 `save_workspace_links` 写回 DB
- 提供"格式化"按钮

**验证**：在面板中修改 JSON 并保存，Portal 重新渲染生效。

## 非目标（v0.4.0 及以后）

- 拖拽排版（Homarr 式 DnD）——本版本配置驱动
- 自定义微件脚本
- 状态监控历史数据/图表
- 多工作台链接的跨工作台拖拽

## 数据模型变更

`workspace_links.links_json` 中链接对象扩展字段（全部可选，向后兼容）：

| 字段 | 类型 | 默认 | 用途 |
|------|------|------|------|
| `monitor` | bool | false | F2 状态探测开关 |
| `span` | [int, int] | [1,1] | F3 Bento 网格尺寸 |
| `peek` | bool | false | F6 Peek View 开关 |

## 事件契约

| 事件 | 方向 | 载荷 |
|------|------|------|
| `service-status-update` | Rust → JS | `{ statuses: [{ url, online, latencyMs }] }` |

## 依赖变更

- 新增 `ureq = "2"`（Cargo.toml，状态探测 HTTP 客户端）

## 发布要求

- 版本号保持 0.3.0
- 全部功能完成后 `tauri build --bundles nsis` 重建
- **不立即归档**——等用户确认后再运行 `scripts/release.ps1` 归档到 `releases/v0.3.0/`
