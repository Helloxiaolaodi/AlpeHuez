## 一、视觉主题重构（index.html + panel.css）

### 1.1 浅色 Mint 主题（保留主题 key `gradient`）

- 冷色调渐变：`#C4F2FE` / `#A8FFE1` / `#C5FDCB` / `#9AFDFF`。
- 卡片材质改为「磨砂亚克力 / 软糖」：白色内阴影 + 同色系弥散光，**去除深色外阴影**。
  ```css
  box-shadow: inset 0 2px 4px rgba(255,255,255,0.8), 0 8px 24px rgba(168,255,225,0.2);
  ```
- 背景：薄荷绿/青空蓝冷色渐变，保留顶部环境光晕但改为冷色调。

### 1.2 深色 Linear 主题（保留主题 key `space`）

- 底色 `#050505`（卡片 `#09090B`），顶部中央紫红径向光晕：
  ```css
  background-image:
    url('data:image/svg+xml,...noise...'),
    radial-gradient(circle at 50% -20%, rgba(120,40,200,0.15) 0%, transparent 60%);
  background-blend-mode: overlay, normal;
  ```
- SVG 噪点纹理（feTurbulence data URI，opacity ~0.03，overlay 混合）。
- 微边框：`border: 1px solid rgba(255,255,255,0.08)` + `inset 0 1px 0 rgba(255,255,255,0.06)`。
- **卡片悬停高光**：`::before` 伪元素上实现跟随鼠标的径向渐变（紫红/品红），鼠标滑过时边缘泛起光晕。
- **删除** `1109770.jpg` 星空壁纸（`--space-bg` 相关 CSS 全部移除）。

### 1.3 主题切换逻辑

- 保留 `localStorage.nav_theme`（`gradient`/`space`）与面板主题同步机制，不破坏现有存储。

### 1.4 字体排版

- 本地打包 Inter woff2（latin 子集），`@font-face` 声明；中文回退 `"PingFang SC", "Microsoft YaHei", "Noto Sans SC"`。
- 监控数字加 `font-variant-numeric: tabular-nums`（VeloMeter、sys stats、能力值等）。
- 大标题 `letter-spacing: -0.02em`；全局 `line-height: 1.6`。

## 七、幽灵终端修复（Rust，必须项）

- 新增辅助函数，Windows 下为所有子进程设置 `CREATE_NO_WINDOW`（0x08000000）：
  ```rust
  #[cfg(target_os = "windows")]
  use std::os::windows::process::CommandExt;
  const CREATE_NO_WINDOW: u32 = 0x08000000;
  fn silent(cmd: &mut Command) { #[cfg(target_os = "windows")] { cmd.creation_flags(CREATE_NO_WINDOW); } }
  ```
- 应用到 `commands.rs` 全部 `std::process::Command`：
  - `run_cmd`（git status/log/add/commit/push）
  - `run_cmd_timeout`（node 脚本）
  - `open_url_scheme`（`cmd /C start`）
  - `route_external_url`（浏览器 spawn）
  - `open_in_system_browser`（回退浏览器 spawn）

## 十、Bug 修复

### 10.1 My Files 跳转 Portal 错误

- **根因**：index.html:6266 `openUrl(...)` 后调用 `setContext('portal')`，强制切回 Portal。
- **修复**：删除 `setContext('portal')`，保持当前视图；webview-stage 已是全局兄弟节点，无需改路由。

### 10.2 巨大黑块

- **根因**：webview-stage 背景 `#FFFFFF` 在深色模式下与加载遮罩层叠产生黑块。
- **修复**：webview-stage 背景改为主题感知的「深空玻璃」材质（深色 `#0B1120` 玻璃 / 浅色白），确保 `inset: 0` 与 z-index 层级正确。

### 10.3 F11 全屏失效

- **根因**：`enterFullscreen()`（index.html:5087）要求 `activeBrowserLabel`，无浏览器标签时 F11 静默失效。
- **修复**：
  - 移除 `!activeBrowserLabel` 守卫，F11 在任何视图可用。
  - CSS：`body.is-fullscreen .view` 改为 `body.is-fullscreen.browsing .view`（无浏览器标签时进入「专注模式」：隐藏顶栏/侧栏，当前视图全屏）。
  - 保留子 webview 的 F11 转发（`CHILD_KEY_JS` → `alpehuez-fullscreen-toggle`）。

### 10.4 Launch Mode 死按钮

- **根因**：Dev Panel 侧栏 `data-dev-tab="appearance"` 按钮无对应面板 tab，纯死按钮。
- **修复**：删除该按钮。后端 `browser_mode`/`get_browser_path`/`get_browser_config` 保留（`openUrl` 仍读取），`list_browsers`/`set_browser_config` 无前端调用，一并从 `lib.rs`/`build.rs`/capabilities 清理。

### 10.5 Rider Abilities 空值（遥测埋点）

- **根因**：Climber XP 仅来自窗口 focus/blur；在 webview 中浏览时父窗口 blur，无法累积。
- **修复**：新增浏览器标签驻留计时器——`activateBrowserTab` 记录开始时间，切换/关闭时按驻留分钟数 `addAbilityXp('climber', minutes * climberMinute)`，45 分钟深度会话加 `climberDeepBonus`。

### 10.6 Aero Loading（破风加载）

- 现有 chainring 加载遮罩（index.html:3794）已存在；按新主题打磨：深色下深空玻璃底 + 霓虹紫牙盘辉光，浅色下薄荷绿牙盘，加载完成平滑淡出。
