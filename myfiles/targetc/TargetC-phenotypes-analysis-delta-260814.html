1. Description

1.1 Study design

The TargetC cohort is an adenoma follow-up study. Every subject in the follow-up cohort was sampled twice:

Group T1 sample T2 sample
Recurrence Re1 Re2
Non_recurrence Non1 Non2

A cross-sectional comparison of the two groups ignores each subject’s own baseline. The statistically correct unit is the within-individual change:

\[\Delta_i = \mathrm{CLR}(T2_i) - \mathrm{CLR}(T1_i)\]

and the analysis compares Recurrence-delta vs Non_recurrence-delta (117 paired subjects: Recurrence = 59, Non_recurrence = 58).

1.3 Statistical methods

  • Per-feature tests: two-sample Wilcoxon rank-sum on the deltas (Recurrence vs Non_recurrence), BH-FDR corrected; paired Wilcoxon (T2 vs T1) within each group as a descriptive check; effect sizes Cliff’s delta and bias-corrected Hedges’ g.
  • ANCOVA: per feature, delta ~ group + baseline, i.e. group effect on the change adjusted for the subject’s own baseline CLR value.
  • Multivariate: PERMANOVA (adonis2, 999 permutations) + betadisper + PCoA on the Euclidean distance of the delta matrix (Aitchison geometry on the paired changes).
  • Composite module scores: curated CAZyme families and HUMAnN3 pathway keywords are collapsed into 7 modules; each is tested with the same Wilcoxon
    • ANCOVA framework.
  • Transition analysis (pathcoverage): per pathway, gain (0->1) or loss (1->0) between T1 and T2 is compared between groups (Wilcoxon + Fisher’s exact test).

# targetc_delta_analysis.R
# ----------------------------------------------------------------------------
# Paired individual-level delta analysis for the TargetC adenoma follow-up cohort.
#
# Design:
#   Every subject in the follow-up cohort was sampled twice (T1, T2):
#     Recurrence     group: Re1 = T1, Re2 = T2   (adenoma recurrence)
#     Non_recurrence group: Non1 = T1, Non2 = T2 (no recurrence)
#   Per subject and per feature we define
#         delta = CLR(T2) - CLR(T1)
#   i.e. the within-individual log-ratio change over the follow-up interval.
#   The cross-sectional comparison is replaced by the between-group comparison
#   of the within-subject deltas:
#         Recurrence-delta  vs  Non_recurrence-delta
#
# Data sources (each analysed with the same delta framework):
#   1. mp4_species            MetaPhlAn4 species relative abundances
#                             (requires a bridge file mapping the mp4 T-numbers
#                              to the profile_column keys, see TARGETC_MP4_BRIDGE)

#   3. humann3_pathcoverage   HUMAnN3 pathway presence/absence -> transition analysis
#   4. microtrait_proportion  microTrait compositional trait proportions (CLR)

#   - per-feature two-sample Wilcoxon rank-sum on delta, BH-corrected

write_tsv <- function(x, path) {
  dir.create(dirname(path), recursive = TRUE, showWarnings = FALSE)

              col.names = TRUE)

# write a matrix, keeping the rownames as an explicit first column

  df <- data.frame(id = rownames(m), m, check.names = FALSE,

}

cliff_delta <- function(x, y) {
  n1 <- length(x); n2 <- length(y)
  if (n1 == 0 || n2 == 0) return(NA_real_)
  sum(vapply(x, function(a) sum(a > y) - sum(a < y), numeric(1))) / (n1 * n2)
}

hedges_g <- function(x, y) {
  n1 <- length(x); n2 <- length(y)
  if (n1 < 2 || n2 < 2) return(NA_real_)
  sp2 <- ((n1 - 1) * var(x) + (n2 - 1) * var(y)) / (n1 + n2 - 2)
  if (sp2 <= 0) return(NA_real_)
  d <- (mean(x) - mean(y)) / sqrt(sp2)
  J <- 1 - 3 / (4 * (n1 + n2) - 9)
  d * J
}

# Multiplicative-replacement + CLR on a samples x features matrix.
# Features with prevalence < min_prevalence (or all-zero) are dropped.
clr_matrix <- function(X, min_prevalence = 0.10, pc_factor = 0.5) {
  n <- nrow(X)
  present <- colSums(X > 0)
  keep <- present >= min_prevalence * n
  X <- X[, keep, drop = FALSE]
  if (ncol(X) == 0) stop("no features pass the prevalence filter")
  minpos <- apply(X, 2, function(v) {
    m <- min(v[v > 0]); if (length(m) == 0) NA_real_ else m
  })
  keep2 <- !is.na(minpos)
  X <- X[, keep2, drop = FALSE]
  minpos <- minpos[keep2]
  pc <- pc_factor * minpos
  Xr <- X
  z <- X == 0
  Xr[z] <- rep(pc, each = n)[z]
  lx <- log(Xr)
  clr <- lx - rowMeans(lx)
  list(clr = clr, kept = colnames(X))
}

# ------------------------- longitudinal design -----------------------------

build_design <- function(annotated) {
  d <- data.frame(subject_id   = annotated$SID,
                  profile_col  = annotated$profile_column,
                  source       = annotated$source,
                  stringsAsFactors = FALSE)
  d$timepoint <- ifelse(d$source %in% c("Re1", "Non1"), "T1",
                 ifelse(d$source %in% c("Re2", "Non2"), "T2", NA))
  d$group <- ifelse(d$source %in% c("Re1", "Re2"), "Recurrence",
             ifelse(d$source %in% c("Non1", "Non2"), "Non_recurrence", NA))
  d <- d[!duplicated(d$profile_col), ]

  t1 <- d[d$timepoint == "T1", c("subject_id", "profile_col", "group")]
  t2 <- d[d$timepoint == "T2", c("subject_id", "profile_col", "group")]
  pairs <- merge(t1, t2, by = "subject_id", suffixes = c("_T1", "_T2"),
                 all = FALSE)
  pairs <- pairs[!is.na(pairs$group_T1) & !is.na(pairs$group_T2), ]
  pairs <- pairs[pairs$group_T1 == pairs$group_T2, ]
  pairs$group <- pairs$group_T1
  names(pairs)[names(pairs) == "profile_col_T1"] <- "sample_T1"
  names(pairs)[names(pairs) == "profile_col_T2"] <- "sample_T2"
  pairs <- pairs[, c("subject_id", "group", "sample_T1", "sample_T2")]
  list(design = d, pairs = pairs)
}

# HUMAnN3 per-sample files: <sample>_<suffix>.tsv with one header line then
# feature<TAB>value rows. Returns a sample x feature matrix (0-filled).
load_humann3 <- function(dir, suffix) {
  files <- list.files(dir, pattern = paste0("_", suffix, "\\.tsv$"),
                      full.names = TRUE)
  if (length(files) == 0) return(NULL)
  cat(sprintf("  reading %d %s files...\n", length(files), suffix))
  mats <- list()
  for (f in files) {
    base <- sub(paste0("_", suffix, "\\.tsv$"), "", basename(f))
    lines <- readLines(f, warn = FALSE)
    if (length(lines) < 2) next
    tab <- read.delim(text = paste(lines[-1], collapse = "\n"),
                      sep = "\t", header = FALSE, check.names = FALSE,
                      stringsAsFactors = FALSE,
                      colClasses = c("character", "numeric"))
    tab <- tab[!grepl("^(UNMAPPED|UNINTEGRATED|UNGROUPED)", tab[, 1]) &
               !grepl("\\|", tab[, 1]), ]
    mats[[base]] <- tab
  }
  if (length(mats) == 0) return(NULL)
  allfeats <- unique(unlist(lapply(mats, function(m) m[, 1]), use.names = FALSE))
  X <- matrix(0, nrow = length(mats), ncol = length(allfeats),
              dimnames = list(names(mats), allfeats))
  for (b in names(mats)) {
    idx <- match(mats[[b]][, 1], allfeats)
    X[b, idx] <- mats[[b]][, 2]
  }
  X
}

# MetaPhlAn4 merged profile: clades x samples (T-numbers). Species rows only.
# Renamed to profile_column keys via the bridge file, then subset to the design.
load_mp4_species <- function(profile_file, bridge_file) {
  if (!file.exists(profile_file)) return(NULL)
  cat("  reading MetaPhlAn4 merged profile...\n")
  mp <- read.delim(profile_file, sep = "\t", check.names = FALSE,
                   row.names = 1, stringsAsFactors = FALSE)
  mp <- mp[grepl("^s__", rownames(mp)), , drop = FALSE]
  if (nrow(mp) == 0) return(NULL)
  X <- t(mp)  # samples x species
  rownames(X) <- sub("\\.mp4$", "", rownames(X))

  if (!file.exists(bridge_file)) {
    cat(sprintf("  WARNING: mp4 bridge file not found (%s); skipping species\n",
                bridge_file))
    return(NULL)
  }
  br <- read.delim(bridge_file, sep = "\t", stringsAsFactors = FALSE,
                   check.names = FALSE)
  if (!all(c("mp4_sample", "profile_column") %in% names(br))) {
    cat("  WARNING: bridge needs columns mp4_sample, profile_column; skipping\n")
    return(NULL)
  }
  br$mp4_sample <- sub("\\.mp4$", "", br$mp4_sample)
  map <- setNames(br$profile_column, br$mp4_sample)
  keep <- rownames(X) %in% names(map)
  X <- X[keep, , drop = FALSE]
  rownames(X) <- map[rownames(X)]
  X <- X[!duplicated(rownames(X)), , drop = FALSE]
  X
}

# Annotated sample x feature matrix (first columns are annotation keys).
# Returns a matrix keyed by profile_column with attr(X, "meta") holding the
# SID/profile_column/source columns (used by align_to_design for key remapping).
load_annotated <- function(file, exclude = c("SID", "profile_column", "source", "sample_id")) {
  if (!file.exists(file)) return(NULL)
  mt <- read.delim(file, sep = "\t", check.names = FALSE, stringsAsFactors = FALSE)
  key <- mt$profile_column
  traits <- setdiff(names(mt), exclude)
  X <- as.matrix(mt[, traits, drop = FALSE])
  rownames(X) <- key
  X[is.na(X)] <- 0
  attr(X, "meta") <- mt[, intersect(c("SID", "profile_column", "source"), names(mt)),
                        drop = FALSE]
  X
}

load_microtrait <- function(file) load_annotated(file)

# Remap a source matrix's rownames to the design's sample keys (pairs$sample_T1/T2)
# via (SID, timepoint). No-op when the source has no SID metadata (e.g. HUMAnN3)
# or its keys already match the design.
align_to_design <- function(X, pairs) {
  meta <- attr(X, "meta")
  if (is.null(meta)) return(X)
  if (all(pairs$sample_T1 %in% rownames(X)) &&
      all(pairs$sample_T2 %in% rownames(X))) return(X)
  tp <- ifelse(meta$source %in% c("Re1", "Non1"), "T1",
        ifelse(meta$source %in% c("Re2", "Non2"), "T2", NA))
  des_t1 <- setNames(pairs$sample_T1, pairs$subject_id)
  des_t2 <- setNames(pairs$sample_T2, pairs$subject_id)
  newkey <- ifelse(tp == "T1", des_t1[meta$SID], des_t2[meta$SID])
  ok <- !is.na(newkey) & !is.na(meta$profile_column) &
        meta$profile_column %in% rownames(X)
  X <- X[meta$profile_column[ok], , drop = FALSE]
  rownames(X) <- newkey[ok]
  X[!duplicated(rownames(X)), , drop = FALSE]
}

# --------------------------- per-feature tests ------------------------------

feature_tests <- function(delta, clr_t1, clr_t2, pairs) {
  grp <- setNames(pairs$group, pairs$subject_id)
  feats <- colnames(delta)
  out <- do.call(rbind, lapply(feats, function(f) {
    re  <- delta[grp == "Recurrence", f]
    non <- delta[grp == "Non_recurrence", f]
    wt <- tryCatch(wilcox.test(re, non), error = function(e) NULL)
    re1 <- clr_t1[grp == "Recurrence", f]
    re2 <- clr_t2[grp == "Recurrence", f]
    n1  <- clr_t1[grp == "Non_recurrence", f]
    n2  <- clr_t2[grp == "Non_recurrence", f]
    pr <- tryCatch(wilcox.test(re1, re2, paired = TRUE)$p.value,
                   error = function(e) NA_real_)
    pn <- tryCatch(wilcox.test(n1, n2, paired = TRUE)$p.value,
                   error = function(e) NA_real_)
    anc <- tryCatch({
      fit <- lm(dv ~ grp + base, data = data.frame(
        dv   = delta[, f],
        grp  = factor(grp, levels = c("Recurrence", "Non_recurrence")),
        base = clr_t1[, f]))
      s <- summary(fit)$coefficients
      data.frame(p_ancova    = s["grpNon_recurrence", "Pr(>|t|)"],
                 ancova_beta = s["grpNon_recurrence", "Estimate"])
    }, error = function(e) data.frame(p_ancova = NA_real_, ancova_beta = NA_real_))
    data.frame(
      feature          = f,
      n_re             = length(re),
      n_non            = length(non),
      mean_delta_re    = mean(re),
      mean_delta_non   = mean(non),
      delta_diff       = mean(re) - mean(non),
      median_delta_re  = median(re),
      median_delta_non = median(non),
      W                = if (is.null(wt)) NA_real_ else unname(wt$statistic),
      p_wilcox         = if (is.null(wt)) NA_real_ else wt$p.value,
      cliff_delta      = cliff_delta(re, non),
      hedges_g         = hedges_g(re, non),
      p_paired_re      = pr,
      p_paired_non     = pn,
      p_ancova         = anc$p_ancova,
      ancova_beta      = anc$ancova_beta,
      mean_clr_t1_re   = mean(re1),
      mean_clr_t2_re   = mean(re2),
      mean_clr_t1_non  = mean(n1),
      mean_clr_t2_non  = mean(n2),
      stringsAsFactors = FALSE)
  }))
  out$p_wilcox_bh   <- p.adjust(out$p_wilcox, method = "BH")
  out$p_paired_re_bh  <- p.adjust(out$p_paired_re, method = "BH")
  out$p_paired_non_bh <- p.adjust(out$p_paired_non, method = "BH")
  out$p_ancova_bh   <- p.adjust(out$p_ancova, method = "BH")
  out$sig_bh <- out$p_wilcox_bh < 0.05
  out[order(out$p_wilcox), ]
}

# ---------------------------- multivariate ---------------------------------

multivariate <- function(delta, pairs, n_perm) {
  grp <- factor(pairs$group, levels = c("Recurrence", "Non_recurrence"))
  dm  <- dist(delta)
  set.seed(1234)
  ad <- adonis2(dm ~ grp, permutations = n_perm)
  bd <- tryCatch(betadisper(dm, grp), error = function(e) NULL)
  pco <- cmdscale(dm, k = 2, eig = TRUE)
  coords <- data.frame(subject_id = rownames(delta),
                       group      = as.character(grp),
                       axis1      = pco$points[, 1],
                       axis2      = pco$points[, 2],
                       stringsAsFactors = FALSE)
  permanova <- data.frame(
    term         = rownames(ad),
    df           = ad$Df,
    sum_of_sq    = ad$SumOfSqs,
    f_stat       = ad$F,
    r2           = ad$R2,
    p            = ad$`Pr(>F)`,
    stringsAsFactors = FALSE)
  betadisp <- NULL
  if (!is.null(bd)) {
    # parametric F-test on group distances (standard betadisper assessment)
    av <- tryCatch(anova(bd), error = function(e) NULL)
    betadisp <- data.frame(
      group_f = if (is.null(av)) NA_real_ else unname(av[["F value"]][1]),
      group_p = if (is.null(av)) NA_real_ else av[["Pr(>F)"]][1],
      stringsAsFactors = FALSE)
  }
  list(permanova = permanova, betadisp = betadisp, coords = coords)
}

# ---------------------- pathcoverage transition tests -----------------------

transition_tests <- function(cov, pairs) {
  t1v <- cov[pairs$sample_T1, , drop = FALSE]
  t2v <- cov[pairs$sample_T2, , drop = FALSE]
  rownames(t1v) <- pairs$subject_id
  rownames(t2v) <- pairs$subject_id
  trans <- t2v - t1v
  v <- apply(trans, 2, var, na.rm = TRUE)
  trans <- trans[, !is.na(v) & v > 0, drop = FALSE]
  grp <- setNames(pairs$group, pairs$subject_id)
  feats <- colnames(trans)
  out <- do.call(rbind, lapply(feats, function(f) {
    re  <- trans[grp == "Recurrence", f]
    non <- trans[grp == "Non_recurrence", f]
    wt  <- tryCatch(wilcox.test(re, non)$p.value, error = function(e) NA_real_)
    ch_re  <- table(factor(re != 0, levels = c(FALSE, TRUE)))
    ch_non <- table(factor(non != 0, levels = c(FALSE, TRUE)))
    ft <- tryCatch(fisher.test(cbind(ch_re, ch_non))$p.value,
                   error = function(e) NA_real_)
    data.frame(
      feature        = f,
      mean_trans_re  = mean(re),
      mean_trans_non = mean(non),
      n_re           = length(re),
      n_non          = length(non),
      n_gain_re      = sum(re == 1),
      n_loss_re      = sum(re == -1),
      n_gain_non     = sum(non == 1),
      n_loss_non     = sum(non == -1),
      p_wilcox       = wt,
      p_fisher       = ft,
      stringsAsFactors = FALSE)
  }))
  out$p_wilcox_bh <- p.adjust(out$p_wilcox, method = "BH")
  out$p_fisher_bh <- p.adjust(out$p_fisher, method = "BH")
  out[order(out$p_wilcox), ]
}

analyze_source <- function(name, X, pairs, compositional, cfg) {
  cat(sprintf("\n=== %s ===\n", name))
  X <- align_to_design(X, pairs)
  present_t1 <- pairs$sample_T1 %in% rownames(X)
  present_t2 <- pairs$sample_T2 %in% rownames(X)
  ok <- present_t1 & present_t2
  sub <- pairs[ok, ]
  cat(sprintf("  paired subjects with both timepoints: %d (Recurrence=%d, Non_recurrence=%d)\n",
              nrow(sub), sum(sub$group == "Recurrence"), sum(sub$group == "Non_recurrence")))
  if (nrow(sub) < 6) { cat("  too few subjects; skipping\n"); return(invisible(NULL)) }

  Xs <- X[unique(c(sub$sample_T1, sub$sample_T2)), , drop = FALSE]
  if (compositional) {
    res <- tryCatch(clr_matrix(Xs, min_prevalence = cfg$min_prev),
                    error = function(e) NULL)
    if (is.null(res)) {
      cat(sprintf("  no features pass the prevalence filter; skipping %s\n", name))
      return(invisible(NULL))
    }
    Xclr <- res$clr
    cat(sprintf("  features after CLR filter: %d\n", ncol(Xclr)))
  } else {
    Xclr <- Xs
  }

  clr_t1 <- Xclr[sub$sample_T1, , drop = FALSE]
  clr_t2 <- Xclr[sub$sample_T2, , drop = FALSE]
  rownames(clr_t1) <- sub$subject_id
  rownames(clr_t2) <- sub$subject_id
  delta <- clr_t2 - clr_t1

  v <- apply(delta, 2, var, na.rm = TRUE)
  delta <- delta[, !is.na(v) & v > 0, drop = FALSE]
  if (ncol(delta) == 0) { cat("  no variable features; skipping\n"); return(invisible(NULL)) }
  cat(sprintf("  variable features for delta tests: %d\n", ncol(delta)))

  st <- feature_tests(delta, clr_t1, clr_t2, sub)
  mv <- multivariate(delta, sub, cfg$n_perm)

  st_dir <- cfg$stats_dir
  write_mat(delta,  file.path(st_dir, paste0("delta_matrix_", name, ".tsv")))
  write_mat(clr_t1, file.path(st_dir, paste0("clr_t1_", name, ".tsv")))
  write_mat(clr_t2, file.path(st_dir, paste0("clr_t2_", name, ".tsv")))
  write_tsv(st,             file.path(st_dir, paste0("per_feature_stats_", name, ".tsv")))
  write_tsv(mv$coords,      file.path(st_dir, paste0("pcoa_", name, ".tsv")))
  write_tsv(rbind(mv$permanova,
                  data.frame(term = "betadisper", df = NA, sum_of_sq = NA,
                             f_stat = if (is.null(mv$betadisp)) NA_real_ else mv$betadisp$group_f,
                             r2 = NA, p = if (is.null(mv$betadisp)) NA_real_ else mv$betadisp$group_p,
                             stringsAsFactors = FALSE)),
            file.path(st_dir, paste0("permanova_", name, ".tsv")))

  n_sig <- sum(st$sig_bh)
  summary_lines <- c(
    sprintf("source: %s", name),
    sprintf("paired subjects: %d (Recurrence=%d, Non_recurrence=%d)",
            nrow(sub), sum(sub$group == "Recurrence"), sum(sub$group == "Non_recurrence")),
    sprintf("features tested: %d", nrow(st)),
    sprintf("features with BH-FDR < 0.05: %d", n_sig),
    sprintf("top 10 by raw p:"))
  top <- st[seq_len(min(10, nrow(st))),
            c("feature", "delta_diff", "p_wilcox", "p_wilcox_bh", "p_ancova", "p_ancova_bh")]
  sink(file.path(st_dir, paste0("analysis_summary_", name, ".txt")))
  cat(paste(summary_lines, collapse = "\n"), "\n")
  print(top, row.names = FALSE)
  sink()
  cat(sprintf("  done. %d significant features at FDR<0.05\n", n_sig))
  invisible(list(stats = st, delta = delta))
}

composite_analysis <- function(cfg, pairs) {
  cat("\n=== composite scores ===\n")
  db <- load_annotated(cfg$dbcan3_prop)
  if (is.null(db)) {
    cat("  dbCAN3 annotated table missing; skipping composite analysis\n")
    return(invisible(NULL))
  }
  db <- align_to_design(db, pairs)
  hu <- if (dir.exists(cfg$humann3_dir)) load_humann3(cfg$humann3_dir, "pathabundance")
        else NULL

  score_rows <- list()
  fams_db <- colnames(db)
  for (m in names(COMPOSITE_MODULES_DB)) {
    f <- intersect(COMPOSITE_MODULES_DB[[m]], fams_db)
    if (length(f) == 0) next
    score_rows[[paste0("db_", m)]] <- data.frame(
      sample_id = rownames(db), data_source = "dbcan3", module = m,
      n_members = length(f), score = rowSums(db[, f, drop = FALSE]),
      stringsAsFactors = FALSE)
  }
  if (!is.null(hu)) {
    for (m in names(COMPOSITE_MODULES_HU)) {
      idx <- grep(COMPOSITE_MODULES_HU[[m]], colnames(hu), ignore.case = TRUE)
      if (length(idx) == 0) next
      score_rows[[paste0("hu_", m)]] <- data.frame(
        sample_id = rownames(hu), data_source = "humann3", module = m,
        n_members = length(idx), score = rowSums(hu[, idx, drop = FALSE]),
        stringsAsFactors = FALSE)
    }
  }
  if (length(score_rows) == 0) {
    cat("  no modules computable; skipping composite analysis\n")
    return(invisible(NULL))
  }
  scores <- do.call(rbind, score_rows)

  minpos <- tapply(scores$score, scores$module, function(v) {
    m <- min(v[v > 0]); if (length(m) == 0) NA_real_ else m
  })
  scores$pc <- 0.5 * minpos[scores$module]
  scores$score_log <- log(scores$score + scores$pc)

  key_tp <- rbind(
    data.frame(sample_id = pairs$sample_T1, subject_id = pairs$subject_id,
               timepoint = "T1", group = pairs$group, stringsAsFactors = FALSE),
    data.frame(sample_id = pairs$sample_T2, subject_id = pairs$subject_id,
               timepoint = "T2", group = pairs$group, stringsAsFactors = FALSE))
  scores <- merge(scores, key_tp, by = "sample_id", all.x = FALSE)
  if (nrow(scores) == 0) {
    cat("  no samples matched the design; skipping composite analysis\n")
    return(invisible(NULL))
  }

  mods <- unique(scores$module)
  out <- do.call(rbind, lapply(mods, function(m) {
    d <- scores[scores$module == m, ]
    t1 <- d[d$timepoint == "T1", c("subject_id", "score_log")]
    t2 <- d[d$timepoint == "T2", c("subject_id", "score_log")]
    pr <- merge(t1, t2, by = "subject_id", suffixes = c("_T1", "_T2"))
    pr$delta <- pr$score_log_T2 - pr$score_log_T1
    pr$group <- pairs$group[match(pr$subject_id, pairs$subject_id)]
    re  <- pr$delta[pr$group == "Recurrence"]
    non <- pr$delta[pr$group == "Non_recurrence"]
    wt <- tryCatch(wilcox.test(re, non), error = function(e) NULL)
    anc <- tryCatch({
      fit <- lm(delta ~ grp + base, data = data.frame(
        delta = pr$delta,
        grp   = factor(pr$group, levels = c("Recurrence", "Non_recurrence")),
        base  = pr$score_log_T1))
      s <- summary(fit)$coefficients
      data.frame(p_ancova    = s["grpNon_recurrence", "Pr(>|t|)"],
                 ancova_beta = s["grpNon_recurrence", "Estimate"])
    }, error = function(e) data.frame(p_ancova = NA_real_, ancova_beta = NA_real_))
    data.frame(
      module = m, label = COMPOSITE_LABELS[[m]],
      data_source = unique(d$data_source), n_members = unique(d$n_members),
      n_re = length(re), n_non = length(non),
      mean_delta_re = mean(re), mean_delta_non = mean(non),
      delta_diff = mean(re) - mean(non),
      p_wilcox = if (is.null(wt)) NA_real_ else wt$p.value,
      cliff_delta = cliff_delta(re, non),
      hedges_g = hedges_g(re, non),
      p_ancova = anc$p_ancova, ancova_beta = anc$ancova_beta,
      stringsAsFactors = FALSE)
  }))
  out$p_wilcox_bh <- p.adjust(out$p_wilcox, method = "BH")
  out$p_ancova_bh <- p.adjust(out$p_ancova, method = "BH")
  out <- out[order(out$p_wilcox), ]

  write_tsv(scores, file.path(cfg$stats_dir, "composite_scores.tsv"))
  write_tsv(out, file.path(cfg$stats_dir, "composite_delta_stats.tsv"))
  summary_lines <- c(
    "composite score delta analysis",
    sprintf("paired subjects: %d (Recurrence=%d, Non_recurrence=%d)",
            nrow(pairs), sum(pairs$group == "Recurrence"),
            sum(pairs$group == "Non_recurrence")),
    sprintf("modules tested: %d", nrow(out)),
    sprintf("modules with BH-FDR < 0.05: %d",
            sum(out$p_wilcox_bh < 0.05, na.rm = TRUE)))
  sink(file.path(cfg$stats_dir, "composite_analysis_summary.txt"))
  cat(paste(summary_lines, collapse = "\n"), "\n")
  print(out[, c("module", "label", "delta_diff", "p_wilcox", "p_wilcox_bh",
                "p_ancova", "p_ancova_bh")], row.names = FALSE)
  sink()
  cat(sprintf("  composite analysis done. %d modules, %d significant at FDR<0.05\n",
              nrow(out), sum(out$p_wilcox_bh < 0.05, na.rm = TRUE)))
  invisible(list(scores = scores, stats = out))
}

main <- function() {
  cfg <- get_config()
  dir.create(cfg$stats_dir, recursive = TRUE, showWarnings = FALSE)
  dir.create(cfg$meta_dir,  recursive = TRUE, showWarnings = FALSE)

  cat("==========================================\n")
  cat("TargetC paired delta analysis\n")
  cat("Output:       ", cfg$out, "\n")
  cat("Sources:      ", paste(cfg$sources, collapse = ", "), "\n")
  cat("Min prevalence:", cfg$min_prev, "\n")
  cat("Start:        ", format(Sys.time()), "\n")
  cat("==========================================\n")

  if (!file.exists(cfg$mt_prop)) {
    stop("annotated microTrait table not found (required for the longitudinal design): ",
         cfg$mt_prop)
  }
  annotated <- read.delim(cfg$mt_prop, sep = "\t", check.names = FALSE,
                          stringsAsFactors = FALSE)
  design <- build_design(annotated)
  pairs  <- design$pairs
  if (nzchar(cfg$meta_paired)) pairs <- override_design(pairs, cfg$meta_paired)
  cat(sprintf("Longitudinal design: %d paired subjects (Recurrence=%d, Non_recurrence=%d)\n",
              nrow(pairs), sum(pairs$group == "Recurrence"),
              sum(pairs$group == "Non_recurrence")))

  # write the design tables (mirrors targetc_build_metadata.py)
  write_tsv(design$design, file.path(cfg$meta_dir, "metadata_longitudinal.tsv"))
  write_tsv(pairs,         file.path(cfg$meta_dir, "metadata_longitudinal_paired.tsv"))

  for (s in cfg$sources) {
    if (s == "humann3_pathabundance" || s == "humann3_pathcoverage") {
      suffix <- sub("humann3_", "", s)
      X <- if (dir.exists(cfg$humann3_dir)) load_humann3(cfg$humann3_dir, suffix)
           else { cat(sprintf("  humann3 dir missing (%s); skipping %s\n",
                              cfg$humann3_dir, s)); NULL }
      if (!is.null(X)) {
        if (s == "humann3_pathcoverage") {
          X[X > 0] <- 1
          trans <- transition_tests(X, pairs)
          st_dir <- cfg$stats_dir
          write_tsv(trans, file.path(st_dir, "transition_stats_humann3_pathcoverage.tsv"))
          write_mat(X, file.path(st_dir, "pathcoverage_matrix_humann3.tsv"),
                    name = "sample_id")
          cat(sprintf("  transition analysis done (%d variable pathways)\n", nrow(trans)))
        } else {
          analyze_source(s, X, pairs, compositional = TRUE, cfg)
        }
      }
    } else if (s == "mp4_species") {
      X <- load_mp4_species(cfg$mp4_profile, cfg$mp4_bridge)
      if (is.null(X)) cat("  species analysis skipped\n")
      else analyze_source(s, X, pairs, compositional = TRUE, cfg)
    } else if (s == "microtrait_proportion") {
      X <- load_microtrait(cfg$mt_prop)
      if (!is.null(X)) analyze_source(s, X, pairs, compositional = TRUE, cfg)
    } else if (s == "microtrait_score") {
      X <- load_microtrait(cfg$mt_score)
      if (!is.null(X)) analyze_source(s, X, pairs, compositional = FALSE, cfg)
    } else if (s == "traitar_proportion") {
      X <- load_annotated(cfg$traitar_prop, exclude = c("SID", "profile_column",
                                                        "source", "sample_id", "score"))
      if (!is.null(X)) analyze_source(s, X, pairs, compositional = TRUE, cfg)
    } else if (s == "traitar_score") {
      X <- load_annotated(cfg$traitar_score, exclude = c("SID", "profile_column",
                                                         "source", "sample_id", "score"))
      if (!is.null(X)) analyze_source(s, X, pairs, compositional = FALSE, cfg)
    } else if (s == "dbcan3_proportion") {
      X <- load_annotated(cfg$dbcan3_prop)
      if (!is.null(X)) analyze_source(s, X, pairs, compositional = TRUE, cfg)
    } else if (s == "dbcan3_score") {
      X <- load_annotated(cfg$dbcan3_score)
      if (!is.null(X)) analyze_source(s, X, pairs, compositional = FALSE, cfg)
    } else {
      cat(sprintf("  unknown source '%s'; skipping\n", s))
    }
  }

  composite_analysis(cfg, pairs)

  cat("\nEnd: ", format(Sys.time()), "\n")
  cat("==========================================\n")
}

volcano_label <- function(x) {

    if (nchar(s) > 40 && grepl(":", s, fixed = TRUE)) {
      parts <- strsplit(s, ":", fixed = TRUE)[[1]]
      s <- trimws(parts[length(parts)])
    }
    paste(strwrap(s, width = 30), collapse = "\n")
  }, character(1))
}

# --------------------------------- main ------------------------------------

main <- function() {
  cfg <- get_config()
  if (!dir.exists(cfg$stats_dir)) {
    stop("stats dir not found: ", cfg$stats_dir,
         "\nRun targetc_delta_analysis.R first.")
  }
  cat("==========================================\n")
  cat("TargetC delta plots\n")
  cat("Stats:   ", cfg$stats_dir, "\n")
  cat("Output:  ", cfg$out, "\n")
  cat("Start:   ", format(Sys.time()), "\n")
  cat("==========================================\n")

  design <- read_design(cfg)

  stat_files <- list.files(cfg$stats_dir, pattern = "^per_feature_stats_.*\\.tsv$",
                           full.names = FALSE)
  for (f in stat_files) {
    name <- sub("^per_feature_stats_(.*)\\.tsv$", "\\1", f)
    st <- read.delim(file.path(cfg$stats_dir, f), sep = "\t",
                     stringsAsFactors = FALSE, check.names = FALSE)
    st <- st[order(st$p_wilcox), ]
    cat(sprintf("\n=== %s ===\n", name))
    delta  <- read_matrix(cfg, "delta_matrix_", name)
    clr_t1 <- read_matrix(cfg, "clr_t1_", name)
    clr_t2 <- read_matrix(cfg, "clr_t2_", name)
    pcoa   <- read.delim(file.path(cfg$stats_dir, paste0("pcoa_", name, ".tsv")),
                         sep = "\t", stringsAsFactors = FALSE, check.names = FALSE)
    perm   <- read.delim(file.path(cfg$stats_dir, paste0("permanova_", name, ".tsv")),
                         sep = "\t", stringsAsFactors = FALSE, check.names = FALSE)
    if (is.null(design)) {
      design <- data.frame(subject_id = rownames(delta),
                           group = pcoa$group[match(rownames(delta), pcoa$subject_id)],
                           stringsAsFactors = FALSE)
    }
    if (!is.null(delta)) fig_pcoa(cfg, name, pcoa, perm)
    fig_volcano(cfg, name, st)
    if (!is.null(delta)) fig_topbox(cfg, name, st, delta, design)
    if (!is.null(clr_t1) && !is.null(clr_t2)) {
      fig_trajectory(cfg, name, st, clr_t1, clr_t2, design)
    }
    if (!is.null(delta)) fig_heatmap(cfg, name, st, delta, design)
    fig_manhattan(cfg, name, st)
  }

  tr_file <- file.path(cfg$stats_dir, "transition_stats_humann3_pathcoverage.tsv")
  if (file.exists(tr_file)) {
    cat("\n=== humann3_pathcoverage transitions ===\n")
    trans <- read.delim(tr_file, sep = "\t", stringsAsFactors = FALSE,
                        check.names = FALSE)
    trans <- trans[order(trans$p_fisher), ]
    fig_transitions(cfg, "humann3_pathcoverage", trans)
  }

  cat("\n=== composite modules ===\n")
  fig_composite(cfg)

  cat("\nEnd: ", format(Sys.time()), "\n")
  cat("==========================================\n")
}

5. Interpretation

  1. No feature or composite module survives multiple-testing correction. Across the seven per-feature sources (1506 tests) and seven composite modules, zero results reach BH-FDR < 0.05. The paired design is sound (117 paired subjects), so this is a genuine null result at the current sample size.
  2. The strongest raw-p candidates are biologically coherent but not significant. Butyrate / succinate-to-butanoate fermentation, denitrification to nitrite, acetate utilization, CBM27/CBM23/GH26, and vitamin B6 pathway gain/loss all point toward Recurrence-associated shifts but do not survive correction.
  3. ANCOVA is more sensitive than the plain delta Wilcoxon (e.g. CBM27 p_wilcox = 0.018 -> p_ancova = 0.00055; Traitar acetate utilization 0.023 -> 0.0024), but no ANCOVA hit survives FDR.
  4. Multivariate structure is absent. PERMANOVA P ranges from 0.241 to 0.998 with R2 about 0.004-0.010; betadisper is not significant.
  5. Implications. At n = 117 paired subjects the cohort is underpowered for ~1500 per-feature tests. The seven composite modules are the right scale and show the expected directions (butyrate, mucin degradation higher in Recurrence) without reaching significance. Next steps: increase sample size or pool timepoints, focus on pre-specified modules, and validate the vitamin B6 / butyrate / mucin leads independently.
