1. Description

1.1 Study design

The TargetC cohort is an adenoma follow-up study. MAG-level genomes were recovered from 393 metagenomic samples, and their microbial phenotypes were predicted with three complementary tools across six clinical groups:

Group Description
N Normal (endoscopy-normal control)
Re1 Recurrence_1 (adenoma recurrence, 1st sampling)
Re2 Recurrence_2 (adenoma recurrence, 2nd sampling)
Non1 Non_recurrence_1 (adenoma non-recurrence, 1st sampling)
Non2 Non_recurrence_2 (adenoma non-recurrence, 2nd sampling)
CRC CRC

The main analysis is the 4-group adenoma follow-up subset (Re1 / Re2 / Non1 / Non2, n = 236 samples, 59 per group): do predicted microbial phenotypes differ by recurrence status or change between samplings?

1.2 Phenotype-prediction tools

Tool Prediction Output
Traitar 67 classical microbial phenotypes per-MAG trait calls -> per-sample proportion / coverage-weighted prevalence
microTrait Hierarchical life-history traits per-MAG binary trait calls -> per-sample proportion / coverage-weighted score
dbCAN3 CAZyme families (GH / GT / PL / CE / AA / CBM) per-MAG CAZyme counts -> per-sample proportion / score / present-count

All tools use the same annotated-table format (SID, profile_column, source, <features...>), so the same downstream visualisation framework is reused.

1.3 Statistical methods

  • Aitchison distance (CLR + Euclidean) for compositional proportion data; zeros handled by multiplicative replacement.
  • PERMANOVA (adonis2, 999 permutations) + betadisper + PCoA with 68% confidence ellipses.
  • Kruskal-Wallis global test (not pairwise Wilcoxon) for 6-group and 4-group comparisons, with BH-FDR correction.
  • Effect sizes: max - min group median (or mean) per trait.
  • dbCAN3: ALDEx2 Monte Carlo CLR (128 Dirichlet samples, Kruskal-Wallis) when installed, with Kruskal-Wallis + BH fallback.
  • Targeted mucin modules: curated CAZyme families collapsed into four biologically-motivated modules.

2. Traitar

2.1 Overview

Traitar predicts 67 classical microbial phenotypes from MAGs. Per-sample trait proportion and coverage-weighted prevalence are compared across the 6 clinical groups and the 4-group adenoma follow-up subset.

Key results (4-group subset): no trait survives BH-FDR (best p = 0.0099, padj = 0.652); largest effect is Trehalose utilization (0.088); PERMANOVA shows no separation (4-group R2 = 0.012, P = 0.523; 6-group R2 = 0.013, P = 0.448).

# CLR transform with zero handling (multiplicative replacement via pseudocount)
clr_transform <- function(mat) {
  # Replace zeros with half the minimum non-zero value per row (standard pseudocount)
  mat_out <- mat
  for (i in seq_len(nrow(mat_out))) {
    row_vals <- mat_out[i, ]
    min_pos <- min(row_vals[row_vals > 0], na.rm = TRUE)
    mat_out[i, row_vals == 0] <- min_pos / 2
  }
  # CLR: log-ratio transform
  gm <- apply(mat_out, 1, function(x) exp(mean(log(x))))
  log(mat_out / gm)
}

cat("\nCreating Figure 5: Aitchison PCoA + PERMANOVA...\n")

make_pcoa <- function(pcov_df, grp_lvls, colors, title_str, out_file) {
  df <- pcov_df %>% filter(!is.na(Group)) %>% filter(Group %in% grp_lvls) %>%
    mutate(Group = factor(Group, levels = grp_lvls))

  mat <- df %>% select(all_of(c("row_id", trait_cols))) %>%
    column_to_rownames("row_id") %>% as.matrix()

  # Remove zero-variance columns
  tv <- apply(mat, 2, var, na.rm = TRUE)
  mat <- mat[, tv > 0]

  # CLR transform (handles zeros with pseudocount)
  clr_mat <- clr_transform(mat)

  # Euclidean distance on CLR = Aitchison distance
  dist_mat <- dist(clr_mat, method = "euclidean")

  # PCoA via cmdscale
  pcoa_res <- cmdscale(dist_mat, k = min(2, nrow(clr_mat) - 1), eig = TRUE)

  # Variance explained (positive eigenvalues only)
  pos_eig <- pcoa_res$eig[pcoa_res$eig > 0]
  var_exp <- round(pos_eig[1:min(2, length(pos_eig))] / sum(pos_eig) * 100, 1)

  scores <- as.data.frame(pcoa_res$points)
  colnames(scores) <- c("PCoA1", "PCoA2")[1:ncol(scores)]
  scores$row_id <- rownames(scores)

  rid_grp <- df %>% select(row_id, Group) %>% distinct()
  scores <- scores %>% left_join(rid_grp, by = "row_id")
  scores$Group <- factor(scores$Group, levels = grp_lvls)

  # PERMANOVA (adonis2)
  grp_vec <- scores$Group[match(labels(dist_mat), scores$row_id)]
  set.seed(42)
  adonis_res <- adonis2(dist_mat ~ grp_vec, permutations = 999)
  p_val <- adonis_res$`Pr(>F)`[1]
  r2 <- round(adonis_res$R2[1], 3)

  # Betadisper test (homogeneity of dispersion)
  beta_disp <- betadisper(dist_mat, grp_vec)
  beta_p <- anova(beta_disp)$`Pr(>F)`[1]

  cat(sprintf("  PERMANOVA: R2=%.3f, p=%.4f | Betadisper p=%.4f\n", r2, p_val, beta_p))

  centroids <- scores %>% group_by(Group) %>%
    summarise(PCoA1 = mean(PCoA1), PCoA2 = mean(PCoA2), .groups = "drop")

  subtitle <- bquote("PERMANOVA: " ~ R^2 == .(r2) ~ ", p" == .(format.pval(p_val, digits = 3)) ~
    " | Dispersion p" == .(format.pval(beta_p, digits = 3)))

  p <- ggplot(scores, aes(x = PCoA1, y = PCoA2, color = Group, fill = Group)) +
    geom_point(alpha = 0.6, size = 2) +
    geom_point(data = centroids, aes(x = PCoA1, y = PCoA2), shape = 21, size = 5, stroke = 1.5, color = "black") +
    stat_ellipse(level = 0.68, linewidth = 0.8, alpha = 0.7) +
    scale_color_manual(values = colors[grp_lvls]) +
    scale_fill_manual(values = colors[grp_lvls]) +
    labs(title = title_str, subtitle = subtitle,
         x = sprintf("PCoA1 (%.1f%%)", var_exp[1]),
         y = if(ncol(scores) >= 2) sprintf("PCoA2 (%.1f%%)", var_exp[2]) else "PCoA2",
         fill = "Group", color = "Group") +
    theme_nature(base_size = 12) +
    theme(legend.position = "right", axis.text.x = element_text(angle = 0, hjust = 0.5))

  ggsave(out_file, p, width = 8, height = 6, dpi = 300)
  list(scores = scores, adonis_r2 = r2, adonis_p = p_val, betadisper_p = beta_p)
}

make_kw_volcano <- function(long_df, title_str, out_file) {
  kw_res <- long_df %>% filter(!is.na(Group)) %>%
    group_by(trait) %>%
    summarise(kw_stat = kruskal.test(wmean ~ Group)$statistic,
              kw_pval = kruskal.test(wmean ~ Group)$p.value, .groups = "drop") %>%
    mutate(kw_padj = p.adjust(kw_pval, method = "BH"),
           neg_log10_padj = -log10(kw_padj)) %>%
    left_join(trait_cat_df, by = "trait") %>% arrange(kw_padj)
  kw_res$category[is.na(kw_res$category)] <- "Other"

  grp_med <- long_df %>% filter(!is.na(Group)) %>%
    group_by(trait, Group) %>% summarise(med = median(wmean, na.rm = TRUE), .groups = "drop")
  eff <- grp_med %>% group_by(trait) %>%
    summarise(effect_size = max(med) - min(med), .groups = "drop")

  kw_volc <- kw_res %>% left_join(eff, by = "trait") %>%
    mutate(category = factor(category, levels = c(names(TRAIT_CATEGORIES), "Other")))
  sig <- kw_volc %>% filter(kw_padj < 0.05) %>% slice_max(order_by = neg_log10_padj, n = 15)

  p <- ggplot(kw_volc, aes(x = effect_size, y = neg_log10_padj, color = category)) +
    geom_point(alpha = 0.7, size = 2) +
    geom_hline(yintercept = -log10(0.05), linetype = "dashed", color = "grey40", linewidth = 0.6) +
    scale_color_manual(values = CAT_COLORS) +
    ggrepel::geom_text_repel(data = sig, aes(label = trait), size = 3, max.overlaps = 20,
      box.padding = 0.4, segment.color = "grey50", segment.size = 0.3) +
    labs(title = title_str,
         x = "Effect Size (max - min group median)", y = expression(-log[10](adj.~p)), color = "Category") +
    theme_nature(base_size = 12)

  ggsave(out_file, p, width = 8, height = 5.5, dpi = 300)
  kw_res
}

# CLR transform with zero handling (multiplicative replacement via pseudocount)
clr_transform <- function(mat) {
  mat_out <- mat
  for (i in seq_len(nrow(mat_out))) {
    row_vals <- mat_out[i, ]
    min_pos <- min(row_vals[row_vals > 0], na.rm = TRUE)
    if (is.finite(min_pos)) mat_out[i, row_vals == 0] <- min_pos / 2
  }
  gm <- apply(mat_out, 1, function(x) exp(mean(log(x))))
  log(mat_out / gm)
}

write_heatmap <- function(pcov_df, tcols, grp_lvls, colors, title, out_file, n_top = 30,
                          width = NULL, height = NULL) {
  hm_df <- pcov_df %>% filter(Group %in% grp_lvls) %>%
    select(all_of(c("row_id", tcols))) %>%
    column_to_rownames("row_id") %>% as.matrix()

  group_anno <- pcov_df %>% filter(Group %in% grp_lvls) %>%
    select(row_id, Group) %>% column_to_rownames("row_id") %>%
    mutate(Group = factor(Group, levels = grp_lvls))

  tv <- apply(hm_df, 2, var, na.rm = TRUE)
  valid <- names(tv)[!is.na(tv) & tv > 0]
  top_traits <- names(sort(tv[valid], decreasing = TRUE))[1:min(n_top, length(valid))]
  hm_mat <- t(hm_df[, top_traits, drop = FALSE])
  rownames(hm_mat) <- display_trait(rownames(hm_mat))

  cat_anno <- trait_cat_df %>% filter(trait %in% top_traits)
  hm_mat <- hm_mat[display_trait(cat_anno$trait), , drop = FALSE]
  rownames(cat_anno) <- rownames(hm_mat)
  obs_cats <- short_category(as.character(cat_anno$category))
  cat_anno$category <- factor(obs_cats, levels = unique(obs_cats))
  cat_anno$trait <- NULL; cat_anno$super_category <- NULL

  n_groups <- length(grp_lvls)
  pheatmap(hm_mat, scale = "row", cluster_rows = TRUE, cluster_cols = TRUE,
    show_colnames = FALSE, show_rownames = TRUE,
    fontsize_row = 9, fontsize_col = 10,
    annotation_col = group_anno, annotation_row = cat_anno,
    annotation_colors = list(Group = colors[grp_lvls],
                             category = CATEGORY_COLORS[as.character(levels(cat_anno$category))]),
    color = colorRampPalette(rev(brewer.pal(11, "RdYlBu")))(100), border_color = NA,
    main = title,
    filename = out_file,
    width = if (is.null(width)) (if (n_groups >= 5) 9 else 7) else width,
    height = if (is.null(height)) 6.5 else height,
    dpi = 300)
}

# 6. Figure 5: Aitchison PCoA + PERMANOVA (with betadisper test)
# ==============================================================================
cat("\nCreating Figure 5: Aitchison PCoA + PERMANOVA...\n")

make_pcoa <- function(pcov_df, grp_lvls, colors, title_str, out_file) {
  df <- pcov_df %>% filter(Group %in% grp_lvls) %>%
    mutate(Group = factor(Group, levels = grp_lvls))

  mat <- df %>% select(all_of(c("row_id", trait_cols))) %>%
    column_to_rownames("row_id") %>% as.matrix()

  # Remove zero-variance columns
  tv <- apply(mat, 2, var, na.rm = TRUE)
  mat <- mat[, tv > 0]

  # CLR transform (handles zeros with pseudocount) -> Aitchison distance
  clr_mat <- clr_transform(mat)
  dist_mat <- dist(clr_mat, method = "euclidean")

  # PCoA via cmdscale
  pcoa_res <- cmdscale(dist_mat, k = min(2, nrow(clr_mat) - 1), eig = TRUE)

  pos_eig <- pcoa_res$eig[pcoa_res$eig > 0]
  var_exp <- round(pos_eig[1:min(2, length(pos_eig))] / sum(pos_eig) * 100, 1)

  scores <- as.data.frame(pcoa_res$points)
  colnames(scores) <- c("PCoA1", "PCoA2")[1:ncol(scores)]
  scores$row_id <- rownames(scores)

  rid_grp <- df %>% select(row_id, Group) %>% distinct()
  scores <- scores %>% left_join(rid_grp, by = "row_id")
  scores$Group <- factor(scores$Group, levels = grp_lvls)

  # PERMANOVA (adonis2)
  grp_vec <- scores$Group[match(labels(dist_mat), scores$row_id)]
  set.seed(42)
  adonis_res <- adonis2(dist_mat ~ grp_vec, permutations = 999)
  p_val <- adonis_res$`Pr(>F)`[1]
  r2 <- round(adonis_res$R2[1], 3)

  # Betadisper test (homogeneity of dispersion)
  beta_disp <- betadisper(dist_mat, grp_vec)
  beta_p <- anova(beta_disp)$`Pr(>F)`[1]

  cat(sprintf("  PERMANOVA: R2=%.3f, p=%.4f | Betadisper p=%.4f\n", r2, p_val, beta_p))

  centroids <- scores %>% group_by(Group) %>%
    summarise(PCoA1 = mean(PCoA1), PCoA2 = mean(PCoA2), .groups = "drop")

  subtitle <- bquote("PERMANOVA: " ~ R^2 == .(r2) ~ ", p" == .(format.pval(p_val, digits = 3)) ~
    " | Dispersion p" == .(format.pval(beta_p, digits = 3)))

  p <- ggplot(scores, aes(x = PCoA1, y = PCoA2, color = Group, fill = Group)) +
    geom_point(alpha = 0.6, size = 2) +
    geom_point(data = centroids, aes(x = PCoA1, y = PCoA2), shape = 21, size = 5, stroke = 1.5, color = "black") +
    stat_ellipse(level = 0.68, linewidth = 0.8, alpha = 0.7) +
    scale_color_manual(values = colors[grp_lvls]) +
    scale_fill_manual(values = colors[grp_lvls]) +
    labs(title = title_str, subtitle = subtitle,
         x = sprintf("PCoA1 (%.1f%%)", var_exp[1]),
         y = if (ncol(scores) >= 2) sprintf("PCoA2 (%.1f%%)", var_exp[2]) else "PCoA2",
         fill = "Group", color = "Group") +
    theme_nature(base_size = 15) +
    theme(legend.position = "right", axis.text.x = element_text(angle = 0, hjust = 0.5))

  ggsave(out_file, p, width = 7.5, height = 5.8, dpi = 300)
  list(scores = scores, adonis_r2 = r2, adonis_p = p_val, betadisper_p = beta_p)
}

make_kw_volcano <- function(long_df, title_str, out_file) {
  kw_res <- long_df %>% filter(!is.na(Group)) %>%
    group_by(trait) %>%
    summarise(kw_stat = kruskal.test(wmean ~ Group)$statistic,
              kw_pval = kruskal.test(wmean ~ Group)$p.value, .groups = "drop") %>%
    mutate(kw_padj = p.adjust(kw_pval, method = "BH"),
           neg_log10_padj = -log10(kw_padj)) %>%
    left_join(trait_cat_df, by = "trait") %>% arrange(kw_padj)

  grp_med <- long_df %>% filter(!is.na(Group)) %>%
    group_by(trait, Group) %>% summarise(med = median(wmean, na.rm = TRUE), .groups = "drop")
  eff <- grp_med %>% group_by(trait) %>%
    summarise(effect_size = max(med) - min(med), .groups = "drop")

  kw_volc <- kw_res %>% left_join(eff, by = "trait") %>%
    mutate(super_category = factor(super_category, levels = names(SUPER_COLORS)))
  sig <- kw_volc %>% filter(kw_padj < 0.05) %>% slice_max(order_by = neg_log10_padj, n = 15)

  p <- ggplot(kw_volc, aes(x = effect_size, y = neg_log10_padj, color = super_category)) +
    geom_point(alpha = 0.7, size = 2.2) +
    geom_hline(yintercept = -log10(0.05), linetype = "dashed", color = "grey40", linewidth = 0.6) +
    scale_color_manual(values = SUPER_COLORS, name = "Super-category") +
    ggrepel::geom_text_repel(data = sig, aes(label = wrap_label(display_trait(trait))),
      size = 3.5, max.overlaps = 25,
      box.padding = 0.4, segment.color = "grey50", segment.size = 0.3, min.segment.length = 0) +
    labs(title = title_str,
         x = "Effect Size (max - min group median)",
         y = expression(-log[10](adjusted ~ italic(p)))) +
    theme_nature(base_size = 15)

  ggsave(out_file, p, width = 8, height = 5.8, dpi = 300)
  kw_res %>% select(trait, super_category, category, kw_stat, kw_pval, kw_padj)
}

clr_transform <- function(mat) {
  mat[is.na(mat)] <- 0
  pos <- mat[mat > 0]
  delta <- if (length(pos) > 0) min(pos) / 2 else 0.5
  mat[mat == 0] <- delta
  t(apply(mat, 1, function(x) log(x) - mean(log(x))))
}

run_beta <- function(prop_wide, group_levels) {
  fams <- get_family_cols(prop_wide)
  dat <- prop_wide %>%
    filter(!is.na(Group)) %>%
    mutate(Group = factor(Group, levels = group_levels))

  mat <- as.matrix(dat[, fams, drop = FALSE])
  rownames(mat) <- dat$sample_id
  clr <- clr_transform(mat)
  d <- dist(clr, method = "euclidean")

  set.seed(42)
  ad <- adonis2(d ~ Group, data = dat, permutations = 999)
  disp <- anova(betadisper(d, dat$Group))

  pcoa <- cmdscale(d, k = 2, eig = TRUE)
  eig <- pcoa$eig[pcoa$eig > 0]
  var_explained <- if (length(eig) >= 2) {
    round(eig[1:2] / sum(eig) * 100, 1)
  } else {
    c(NA_real_, NA_real_)
  }

  scores <- as.data.frame(pcoa$points)
  colnames(scores) <- c("PCoA1", "PCoA2")
  scores$sample_id <- rownames(scores)
  scores <- scores %>%
    left_join(dat %>% select(sample_id, Group), by = "sample_id")

  list(
    scores = scores,
    var_explained = var_explained,
    r2 = ad$R2[1],
    p = ad$`Pr(>F)`[1],
    disp_p = disp$`Pr(>F)`[1]
  )
}

differential_analysis <- function(prop_long, count_wide, group_levels) {
  fams <- get_family_cols(count_wide)
  dat <- count_wide %>%
    filter(!is.na(Group)) %>%
    mutate(Group = factor(Group, levels = group_levels))

  present_fams <- fams[
    colSums(dat[, fams, drop = FALSE] > 0, na.rm = TRUE) > 0
  ]

  use_aldex <- requireNamespace("ALDEx2", quietly = TRUE)
  method <- "Kruskal-Wallis + BH (ALDEx2 not installed)"
  res <- NULL

  if (use_aldex && length(present_fams) > 1) {
    count_mat <- as.matrix(dat[, present_fams, drop = FALSE])
    rownames(count_mat) <- dat$sample_id
    set.seed(42)
    al <- tryCatch(
      ALDEx2::aldex(
        count_mat,
        dat$Group,
        mc.samples = 128,
        test = "kw",
        effect = TRUE,
        denom = "all"
      ),
      error = function(e) e
    )

    if (!inherits(al, "error")) {
      res <- data.frame(
        family = rownames(al),
        p.value = al$kw.ep,
        FDR = al$kw.eBH,
        aldex_effect = al$effect,
        stringsAsFactors = FALSE
      )
      method <- "ALDEx2 Kruskal-Wallis (Monte Carlo CLR; 128 Dirichlet samples)"
      use_aldex <- TRUE
    } else {
      use_aldex <- FALSE
      warning("ALDEx2 failed; falling back to Kruskal-Wallis: ", conditionMessage(al))
    }
  } else {
    use_aldex <- FALSE
  }

  if (!use_aldex) {
    res <- prop_long %>%
      group_by(family) %>%
      summarise(
        p.value = suppressWarnings(
          tryCatch(
            kruskal.test(proportion, Group)$p.value,
            error = function(e) NA_real_
          )
        ),
        .groups = "drop"
      )
    res$FDR <- NA_real_
    idx <- !is.na(res$p.value)
    res$FDR[idx] <- p.adjust(res$p.value[idx], method = "BH")
    res$aldex_effect <- NA_real_
  }

  stats <- prop_long %>%
    group_by(family, Group) %>%
    summarise(
      mean_prop = mean(proportion, na.rm = TRUE),
      median_prop = median(proportion, na.rm = TRUE),
      sd_prop = sd(proportion, na.rm = TRUE),
      n_samples = n(),
      .groups = "drop"
    )

  median_wide <- stats %>%
    select(family, Group, median_prop) %>%
    pivot_wider(names_from = Group, values_from = median_prop)
  mean_wide <- stats %>%
    select(family, Group, mean_prop) %>%
    pivot_wider(names_from = Group, values_from = mean_prop)

  med_cols <- setdiff(colnames(median_wide), "family")
  mean_cols <- setdiff(colnames(mean_wide), "family")
  median_mat <- as.matrix(median_wide[, med_cols, drop = FALSE])
  mean_mat <- as.matrix(mean_wide[, mean_cols, drop = FALSE])

  effect_size <- apply(
    median_mat,
    1,
    function(x) max(x, na.rm = TRUE) - min(x, na.rm = TRUE)
  )
  log2fc <- log2(
    (apply(median_mat, 1, max, na.rm = TRUE) + 1e-6) /
      (apply(median_mat, 1, min, na.rm = TRUE) + 1e-6)
  )
  mean_range <- apply(
    mean_mat,
    1,
    function(x) max(x, na.rm = TRUE) - min(x, na.rm = TRUE)
  )

  effect_df <- data.frame(
    family = median_wide$family,
    effect_size = effect_size,
    log2FC = log2fc,
    mean_range = mean_range,
    stringsAsFactors = FALSE
  )

  res <- res %>%
    left_join(effect_df, by = "family") %>%
    left_join(median_wide, by = "family") %>%
    left_join(mean_wide, by = "family") %>%
    mutate(class = cazyme_class(family)) %>%
    arrange(FDR, desc(abs(effect_size)))

  attr(res, "method") <- method
  res
}

# Pairwise comparison results (written only under dbcan3-plot-02/pairwise/)
# ============================================================================
pairwise_groups <- function(prop_long, group_levels) {
  group_levels <- group_levels[group_levels %in% prop_long$Group]
  if (length(group_levels) < 2) {
    return(data.frame())
  }

  combs <- combn(group_levels, 2, simplify = FALSE)
  out <- lapply(combs, function(grp) {
    g1 <- grp[1]
    g2 <- grp[2]
    dat <- prop_long %>%
      filter(Group %in% grp) %>%
      mutate(Group = factor(Group, levels = grp))

    res <- dat %>%
      group_by(family) %>%
      summarise(
        n1 = sum(Group == g1),
        n2 = sum(Group == g2),
        median1 = median(proportion[Group == g1], na.rm = TRUE),
        median2 = median(proportion[Group == g2], na.rm = TRUE),
        mean1 = mean(proportion[Group == g1], na.rm = TRUE),
        mean2 = mean(proportion[Group == g2], na.rm = TRUE),
        p.value = suppressWarnings(
          tryCatch(
            wilcox.test(
              proportion[Group == g1],
              proportion[Group == g2]
            )$p.value,
            error = function(e) NA_real_
          )
        ),
        .groups = "drop"
      )
    res$FDR <- NA_real_
    idx <- !is.na(res$p.value)
    res$FDR[idx] <- p.adjust(res$p.value[idx], method = "BH")
    res$log2FC <- log2(
      (res$median1 + 1e-6) / (res$median2 + 1e-6)
    )
    res$effect_size <- res$median1 - res$median2
    res$group1 <- g1
    res$group2 <- g2
    res$comparison <- paste0(g1, "_vs_", g2)
    res$class <- cazyme_class(res$family)
    res
  })

  bind_rows(out)
}

write_pairwise_matrices <- function(pairwise, tables_dir, prefix = "cazyme") {
  if (nrow(pairwise) == 0) {
    return(invisible(NULL))
  }

  comparisons <- unique(pairwise$comparison)
  families <- unique(pairwise$family)

  matrix_from_pairwise <- function(value_col) {
    mat <- matrix(
      NA_real_,
      nrow = length(families),
      ncol = length(comparisons),
      dimnames = list(families, comparisons)
    )
    for (i in seq_len(nrow(pairwise))) {
      mat[pairwise$family[i], pairwise$comparison[i]] <-
        pairwise[[value_col]][i]
    }
    mat
  }

  write_results(
    cbind(
      family = rownames(matrix_from_pairwise("log2FC")),
      as.data.frame(matrix_from_pairwise("log2FC"), check.names = FALSE)
    ),
    file.path(tables_dir, paste0(prefix, "_pairwise_log2FC_matrix.tsv"))
  )
  write_results(
    cbind(
      family = rownames(matrix_from_pairwise("FDR")),
      as.data.frame(matrix_from_pairwise("FDR"), check.names = FALSE)
    ),
    file.path(tables_dir, paste0(prefix, "_pairwise_FDR_matrix.tsv"))
  )
  write_results(
    cbind(
      family = rownames(matrix_from_pairwise("effect_size")),
      as.data.frame(matrix_from_pairwise("effect_size"), check.names = FALSE)
    ),
    file.path(tables_dir, paste0(prefix, "_pairwise_effect_size_matrix.tsv"))
  )
}

save_pairwise_heatmap <- function(
  pairwise,
  filename,
  width = 6,
  height = 9
) {
  if (nrow(pairwise) == 0) {
    return(invisible(NULL))
  }

  sig_fams <- pairwise %>%
    filter(!is.na(FDR), FDR < 0.05) %>%
    pull(family) %>%
    unique()
  if (length(sig_fams) == 0) {
    sig_fams <- pairwise %>%
      group_by(family) %>%
      summarise(min_fdr = min(FDR, na.rm = TRUE), .groups = "drop") %>%
      arrange(min_fdr) %>%
      head(40) %>%
      pull(family)
  }
  if (length(sig_fams) == 0) {
    return(invisible(NULL))
  }

  mat <- pairwise %>%
    filter(family %in% sig_fams) %>%
    select(family, comparison, log2FC) %>%
    pivot_wider(names_from = comparison, values_from = log2FC) %>%
    column_to_rownames("family") %>%
    as.matrix()
  mat[is.na(mat)] <- 0

  finite_vals <- mat[is.finite(mat)]
  if (any(is.infinite(mat))) {
    max_abs <- max(abs(finite_vals), na.rm = TRUE)
    mat[is.infinite(mat)] <- sign(mat[is.infinite(mat)]) * max_abs
  }
  if (max(abs(mat), na.rm = TRUE) == 0) {
    return(invisible(NULL))
  }
  lim <- max(abs(mat), na.rm = TRUE)

  ann_row <- data.frame(
    Class = cazyme_class(rownames(mat)),
    row.names = rownames(mat)
  )

  pheatmap(
    mat,
    cluster_rows = TRUE,
    cluster_cols = TRUE,
    annotation_row = ann_row,
    annotation_colors = list(Class = CLASS_COLORS),
    color = colorRampPalette(c("#2166AC", "white", "#B2182B"))(100),
    breaks = seq(-lim, lim, length.out = 101),
    border_color = "grey85",
    show_rownames = TRUE,
    show_colnames = TRUE,
    fontsize_row = 11,
    fontsize_col = 12,
    main = "Pairwise Log2FC (FDR-significant families)",
    filename = filename,
    width = width,
    height = height,
    dpi = 300
  )
}

run_pairwise_outputs <- function(
  prop_cov,
  group_levels,
  output_dir,
  title_tag
) {
  dir.create(file.path(output_dir, "tables"), recursive = TRUE, showWarnings = FALSE)
  tables_dir <- file.path(output_dir, "tables")

  cat("\nPairwise processing:", title_tag, "->", output_dir, "\n")

  prop_long <- make_long(prop_cov, "proportion")
  pairwise <- pairwise_groups(prop_long, group_levels)

  if (nrow(pairwise) == 0) {
    cat("  No pairwise comparisons produced.\n")
    return(invisible(NULL))
  }

  write_results(
    pairwise,
    file.path(tables_dir, "cazyme_pairwise_results.tsv")
  )
  write_pairwise_matrices(pairwise, tables_dir)

  comparison_summary <- pairwise %>%
    group_by(comparison, group1, group2, n1, n2) %>%
    summarise(
      n_families = n(),
      n_significant_FDR_0.05 = sum(FDR < 0.05, na.rm = TRUE),
      n_upregulated_in_group1 = sum(log2FC > 0 & FDR < 0.05, na.rm = TRUE),
      n_downregulated_in_group1 = sum(log2FC < 0 & FDR < 0.05, na.rm = TRUE),
      .groups = "drop"
    ) %>%
    arrange(comparison)
  write_results(
    comparison_summary,
    file.path(tables_dir, "cazyme_pairwise_comparison_summary.tsv")
  )

  save_pairwise_heatmap(
    pairwise,
    file.path(output_dir, "figS2_pairwise_differential_heatmap.png"),
    width = 6,
    height = 9
  )

  comparisons <- unique(pairwise$comparison)
  for (cc in comparisons) {
    cc_dat <- pairwise %>% filter(comparison == cc)
    prefix <- paste0(
      "figS1_pairwise_volcano_",
      gsub("[^A-Za-z0-9_]+", "_", cc)
    )
    save_figure(
      plot_volcano(
        cc_dat,
        group_levels,
        paste(title_tag, "CAZyme Pairwise Volcano:", cc),
        subtitle = "Wilcoxon rank-sum test with BH FDR; effect size = median1 - median2",
        x_label = "Effect size (median group1 - median group2)"
      ),
      prefix,
      output_dir,
      width = 5.5,
      height = 5
    )
  }

  cat("  Finished pairwise:", title_tag, "\n")
}

make_metric_summary <- function(metric_wides, group_levels) {
  fams <- get_family_cols(metric_wides[[1]])
  out <- lapply(names(metric_wides), function(nm) {
    metric_wides[[nm]] %>%
      filter(!is.na(Group)) %>%
      select(sample_id, Group, all_of(fams)) %>%
      pivot_longer(all_of(fams), names_to = "family", values_to = "value") %>%
      group_by(Group, family) %>%
      summarise(
        mean = mean(value, na.rm = TRUE),
        median = median(value, na.rm = TRUE),
        sd = sd(value, na.rm = TRUE),
        n_samples = n(),
        .groups = "drop"
      ) %>%
      mutate(
        metric = nm,
        class = cazyme_class(family),
        Group = factor(Group, levels = group_levels)
      )
  })
  bind_rows(out)
}

module_pairwise <- function(mod_agg) {
  group_levels <- levels(mod_agg$Group)
  group_levels <- group_levels[group_levels %in% mod_agg$Group]
  if (length(group_levels) < 2) {
    return(data.frame())
  }
  combs <- combn(group_levels, 2, simplify = FALSE)
  out <- lapply(unique(mod_agg$module_key), function(mk) {
    d <- mod_agg %>% filter(module_key == mk)
    mod_label <- unique(d$module)
    lapply(combs, function(grp) {
      g1 <- grp[1]
      g2 <- grp[2]
      dat <- d %>% filter(Group %in% grp) %>% mutate(Group = factor(Group, levels = grp))
      data.frame(
        module_key = mk,
        module = mod_label,
        comparison = paste0(g1, "_vs_", g2),
        group1 = g1,
        group2 = g2,
        n1 = sum(dat$Group == g1, na.rm = TRUE),
        n2 = sum(dat$Group == g2, na.rm = TRUE),
        median1 = median(dat$module_proportion[dat$Group == g1], na.rm = TRUE),
        median2 = median(dat$module_proportion[dat$Group == g2], na.rm = TRUE),
        mean1 = mean(dat$module_proportion[dat$Group == g1], na.rm = TRUE),
        mean2 = mean(dat$module_proportion[dat$Group == g2], na.rm = TRUE),
        p.value = suppressWarnings(
          tryCatch(
            wilcox.test(
              dat$module_proportion[dat$Group == g1],
              dat$module_proportion[dat$Group == g2]
            )$p.value,
            error = function(e) NA_real_
          )
        ),
        stringsAsFactors = FALSE
      )
    }) %>% bind_rows()
  }) %>% bind_rows()

  if (nrow(out) == 0) {
    return(out)
  }
  out <- out %>%
    group_by(module_key) %>%
    mutate(
      FDR = if (all(is.na(p.value))) NA_real_ else p.adjust(p.value, method = "BH")
    ) %>%
    ungroup()
  out$log2FC <- log2((out$median1 + 1e-6) / (out$median2 + 1e-6))
  out$effect_size <- out$median1 - out$median2
  out
}

# ============================================================================

clr_transform <- function(mat) {
  mat[is.na(mat)] <- 0
  pos <- mat[mat > 0]
  delta <- if (length(pos) > 0) min(pos) / 2 else 0.5
  mat[mat == 0] <- delta
  t(apply(mat, 1, function(x) log(x) - mean(log(x))))
}

run_beta <- function(prop_wide, group_levels) {
  fams <- get_family_cols(prop_wide)
  dat <- prop_wide %>%
    filter(!is.na(Group)) %>%
    mutate(Group = factor(Group, levels = group_levels))

  mat <- as.matrix(dat[, fams, drop = FALSE])
  rownames(mat) <- dat$sample_id
  clr <- clr_transform(mat)
  d <- dist(clr, method = "euclidean")

  set.seed(42)
  ad <- adonis2(d ~ Group, data = dat, permutations = 999)
  disp <- anova(betadisper(d, dat$Group))

  pcoa <- cmdscale(d, k = 2, eig = TRUE)
  eig <- pcoa$eig[pcoa$eig > 0]
  var_explained <- if (length(eig) >= 2) {
    round(eig[1:2] / sum(eig) * 100, 1)
  } else {
    c(NA_real_, NA_real_)
  }

  scores <- as.data.frame(pcoa$points)
  colnames(scores) <- c("PCoA1", "PCoA2")
  scores$sample_id <- rownames(scores)
  scores <- scores %>%
    left_join(dat %>% select(sample_id, Group), by = "sample_id")

  list(
    scores = scores,
    var_explained = var_explained,
    r2 = ad$R2[1],
    p = ad$`Pr(>F)`[1],
    disp_p = disp$`Pr(>F)`[1]
  )
}

plot_pcoa <- function(beta, group_levels, title) {
  scores <- beta$scores
  centroids <- scores %>%

# ============================================================================
# Targeted-family differential analysis
# ============================================================================
differential_analysis <- function(prop_long, count_wide, group_levels) {
  fams <- get_family_cols(count_wide)
  dat <- count_wide %>%
    filter(!is.na(Group)) %>%
    mutate(Group = factor(Group, levels = group_levels))

  present_fams <- fams[
    colSums(dat[, fams, drop = FALSE] > 0, na.rm = TRUE) > 0
  ]

  use_aldex <- requireNamespace("ALDEx2", quietly = TRUE)
  method <- "Kruskal-Wallis + BH (ALDEx2 not installed)"
  res <- NULL

  if (use_aldex && length(present_fams) > 1) {
    count_mat <- as.matrix(dat[, present_fams, drop = FALSE])
    rownames(count_mat) <- dat$sample_id
    set.seed(42)
    al <- tryCatch(
      ALDEx2::aldex(
        count_mat,
        dat$Group,
        mc.samples = 128,
        test = "kw",
        effect = TRUE,
        denom = "all"
      ),
      error = function(e) e
    )

    if (!inherits(al, "error")) {
      res <- data.frame(
        family = rownames(al),
        p.value = al$kw.ep,
        FDR = al$kw.eBH,
        aldex_effect = al$effect,
        stringsAsFactors = FALSE
      )
      method <- "ALDEx2 Kruskal-Wallis (Monte Carlo CLR; 128 Dirichlet samples)"
      use_aldex <- TRUE
    } else {
      use_aldex <- FALSE
      warning("ALDEx2 failed; falling back to Kruskal-Wallis: ", conditionMessage(al))
    }
  } else {
    use_aldex <- FALSE
  }

  if (!use_aldex) {
    res <- prop_long %>%
      group_by(family) %>%
      summarise(
        p.value = suppressWarnings(
          tryCatch(
            kruskal.test(proportion, Group)$p.value,
            error = function(e) NA_real_
          )
        ),
        .groups = "drop"
      )
    res$FDR <- NA_real_
    idx <- !is.na(res$p.value)
    res$FDR[idx] <- p.adjust(res$p.value[idx], method = "BH")
    res$aldex_effect <- NA_real_
  }

  stats <- prop_long %>%
    group_by(family, Group) %>%
    summarise(
      mean_prop = mean(proportion, na.rm = TRUE),
      median_prop = median(proportion, na.rm = TRUE),
      sd_prop = sd(proportion, na.rm = TRUE),
      n_samples = n(),
      .groups = "drop"
    )

  median_wide <- stats %>%
    select(family, Group, median_prop) %>%
    pivot_wider(names_from = Group, values_from = median_prop)
  mean_wide <- stats %>%
    select(family, Group, mean_prop) %>%
    pivot_wider(names_from = Group, values_from = mean_prop)

  med_cols <- setdiff(colnames(median_wide), "family")
  mean_cols <- setdiff(colnames(mean_wide), "family")
  median_mat <- as.matrix(median_wide[, med_cols, drop = FALSE])
  mean_mat <- as.matrix(mean_wide[, mean_cols, drop = FALSE])

  effect_size <- apply(
    median_mat,
    1,
    function(x) max(x, na.rm = TRUE) - min(x, na.rm = TRUE)
  )
  log2fc <- log2(
    (apply(median_mat, 1, max, na.rm = TRUE) + 1e-6) /
      (apply(median_mat, 1, min, na.rm = TRUE) + 1e-6)
  )
  mean_range <- apply(
    mean_mat,
    1,
    function(x) max(x, na.rm = TRUE) - min(x, na.rm = TRUE)
  )

  effect_df <- data.frame(
    family = median_wide$family,
    effect_size = effect_size,
    log2FC = log2fc,
    mean_range = mean_range,
    stringsAsFactors = FALSE
  )

  res <- res %>%
    left_join(effect_df, by = "family") %>%
    left_join(median_wide, by = "family") %>%
    left_join(mean_wide, by = "family") %>%
    mutate(class = cazyme_class(family)) %>%
    arrange(FDR, desc(abs(effect_size)))

  attr(res, "method") <- method
  res
}

pairwise_groups <- function(prop_long, group_levels) {
  group_levels <- group_levels[group_levels %in% prop_long$Group]
  if (length(group_levels) < 2) {
    return(data.frame())
  }

  combs <- combn(group_levels, 2, simplify = FALSE)
  out <- lapply(combs, function(grp) {
    g1 <- grp[1]
    g2 <- grp[2]
    dat <- prop_long %>%
      filter(Group %in% grp) %>%
      mutate(Group = factor(Group, levels = grp))

    res <- dat %>%
      group_by(family) %>%
      summarise(
        n1 = sum(Group == g1),
        n2 = sum(Group == g2),
        median1 = median(proportion[Group == g1], na.rm = TRUE),
        median2 = median(proportion[Group == g2], na.rm = TRUE),
        mean1 = mean(proportion[Group == g1], na.rm = TRUE),
        mean2 = mean(proportion[Group == g2], na.rm = TRUE),
        p.value = suppressWarnings(
          tryCatch(
            wilcox.test(
              proportion[Group == g1],
              proportion[Group == g2]
            )$p.value,
            error = function(e) NA_real_
          )
        ),
        .groups = "drop"
      )
    res$FDR <- NA_real_
    idx <- !is.na(res$p.value)
    res$FDR[idx] <- p.adjust(res$p.value[idx], method = "BH")
    res$log2FC <- log2(
      (res$median1 + 1e-6) / (res$median2 + 1e-6)
    )
    res$effect_size <- res$median1 - res$median2
    res$group1 <- g1
    res$group2 <- g2
    res$comparison <- paste0(g1, "_vs_", g2)
    res
  })

  bind_rows(out)
}

write_pairwise_matrices <- function(pairwise, tables_dir, prefix = "mucin") {
  if (nrow(pairwise) == 0) {
    return(invisible(NULL))
  }

  comparisons <- unique(pairwise$comparison)
  families <- unique(pairwise$family)

  matrix_from_pairwise <- function(value_col) {
    mat <- matrix(
      NA_real_,
      nrow = length(families),
      ncol = length(comparisons),
      dimnames = list(families, comparisons)
    )
    for (i in seq_len(nrow(pairwise))) {
      mat[pairwise$family[i], pairwise$comparison[i]] <-
        pairwise[[value_col]][i]
    }
    mat
  }

  write_results(
    cbind(
      family = rownames(matrix_from_pairwise("log2FC")),
      as.data.frame(matrix_from_pairwise("log2FC"), check.names = FALSE)
    ),
    file.path(tables_dir, paste0(prefix, "_pairwise_log2FC_matrix.tsv"))
  )
  write_results(
    cbind(
      family = rownames(matrix_from_pairwise("FDR")),
      as.data.frame(matrix_from_pairwise("FDR"), check.names = FALSE)
    ),
    file.path(tables_dir, paste0(prefix, "_pairwise_FDR_matrix.tsv"))
  )
  write_results(
    cbind(
      family = rownames(matrix_from_pairwise("effect_size")),
      as.data.frame(matrix_from_pairwise("effect_size"), check.names = FALSE)
    ),
    file.path(tables_dir, paste0(prefix, "_pairwise_effect_size_matrix.tsv"))
  )
}

save_pairwise_heatmap <- function(
  pairwise,
  filename,
  width = 6.5,
  height = 9
) {
  if (nrow(pairwise) == 0) {
    return(invisible(NULL))
  }

  sig_fams <- pairwise %>%
    filter(!is.na(FDR), FDR < 0.05) %>%
    pull(family) %>%
    unique()
  if (length(sig_fams) == 0) {
    sig_fams <- pairwise %>%
      group_by(family) %>%
      summarise(min_fdr = min(FDR, na.rm = TRUE), .groups = "drop") %>%
      arrange(min_fdr) %>%
      head(40) %>%
      pull(family)
  }
  if (length(sig_fams) == 0) {
    return(invisible(NULL))
  }

  mat <- pairwise %>%
    filter(family %in% sig_fams) %>%
    select(family, comparison, log2FC) %>%
    pivot_wider(names_from = comparison, values_from = log2FC) %>%
    column_to_rownames("family") %>%
    as.matrix()
  mat[is.na(mat)] <- 0

  finite_vals <- mat[is.finite(mat)]
  if (any(is.infinite(mat))) {
    max_abs <- max(abs(finite_vals), na.rm = TRUE)
    mat[is.infinite(mat)] <- sign(mat[is.infinite(mat)]) * max_abs
  }
  if (max(abs(mat), na.rm = TRUE) == 0) {
    return(invisible(NULL))
  }
  lim <- max(abs(mat), na.rm = TRUE)

  ann_vals <- factor(
    primary_module(rownames(mat)),
    levels = names(MODULE_COLORS)
  )
  ann_row <- data.frame(
    Module = ann_vals,
    row.names = rownames(mat)
  )

  pheatmap(
    mat,
    cluster_rows = TRUE,
    cluster_cols = TRUE,
    annotation_row = ann_row,
    annotation_colors = list(Module = MODULE_COLORS),
    color = colorRampPalette(c("#2166AC", "white", "#B2182B"))(100),
    breaks = seq(-lim, lim, length.out = 101),
    border_color = "grey85",
    show_rownames = TRUE,
    show_colnames = TRUE,
    fontsize_row = 11,
    fontsize_col = 12,
    main = "Pairwise Log2FC (FDR-significant target families)",
    filename = filename,
    width = width,
    height = height,
    dpi = 300
  )
}

run_mucin_outputs <- function(
  prop_cov,
  count_wide,
  group_levels,
  output_dir,
  title_tag
) {
  dir.create(file.path(output_dir, "tables"), recursive = TRUE, showWarnings = FALSE)
  tables_dir <- file.path(output_dir, "tables")

  cat("\nTargeted module processing:", title_tag, "->", output_dir, "\n")

  tfams <- target_families(prop_cov)
  cat("  Target families available:", length(tfams), "\n")
  missing <- setdiff(unique(unlist(MODULES)), tfams)
  if (length(missing) > 0) {
    cat("  Not found in data:", paste(missing, collapse = ", "), "\n")
  }
  if (length(tfams) == 0) {
    cat("  No target families available. Skipping.\n")
    return(invisible(NULL))
  }

  prop_r <- restrict_to_targets(prop_cov, tfams)
  count_r <- restrict_to_targets(count_wide, intersect(tfams, colnames(count_wide)))

  # --- module aggregate ---
  mod_agg <- module_aggregate(prop_cov, count_wide)
  mod_agg$Group <- factor(mod_agg$Group, levels = group_levels)
  mod_group_sum <- module_group_summary(mod_agg)
  mod_kw <- module_kw_stats(mod_agg)
  write_results(
    left_join(mod_group_sum, mod_kw, by = c("module_key", "module")),
    file.path(tables_dir, "mucin_module_aggregate_summary.tsv")
  )
  write_results(
    mod_agg,
    file.path(tables_dir, "mucin_module_long.tsv")
  )
  save_figure(
    plot_module_boxplots(
      mod_agg,
      group_levels,
      paste(title_tag, "Targeted Module Degradation Potential")
    ),
    "figM1_mucin_module_boxplots",
    output_dir,
    width = 7,
    height = 5.5
  )

  # --- CLR PCoA restricted to target families ---
  beta <- run_beta(prop_r, group_levels)
  write_results(
    data.frame(
      analysis = title_tag,
      method = "Aitchison PCoA (CLR + Euclidean distance) on target families",
      PERMANOVA_R2 = beta$r2,
      PERMANOVA_P = beta$p,
      Dispersion_P = beta$disp_p,
      stringsAsFactors = FALSE
    ),
    file.path(tables_dir, "mucin_permanova_stats.tsv")
  )
  write_results(
    beta$scores,
    file.path(tables_dir, "mucin_aitchison_pcoa_scores.tsv")
  )
  save_figure(
    plot_pcoa(beta, group_levels, paste(title_tag, "Targeted CAZyme Aitchison PCoA")),
    "figM5_mucin_clr_pcoa",
    output_dir,
    width = 8,
    height = 6
  )

  # --- family-level differential ---
  prop_long <- make_long(prop_r, "proportion")
  count_long <- make_long(count_r, "count")
  diff_res <- differential_analysis(prop_long, count_r, group_levels)
  diff_res$module <- module_annotation(diff_res$family)
  diff_res$primary_module <- primary_module(diff_res$family)
  cat("  Differential method:", attr(diff_res, "method"), "\n")
  write_results(
    diff_res,
    file.path(tables_dir, "mucin_target_family_differential.tsv")
  )
  save_figure(
    plot_volcano_module(
      diff_res,
      paste(title_tag, "Targeted CAZyme Differential Volcano")
    ),
    "figM2_mucin_family_volcano",
    output_dir,
    width = 8,
    height = 6
  )
  save_figure(
    plot_top_family_boxplots(prop_long, diff_res, group_levels),
    "figM3_mucin_top_family_boxplots",
    output_dir,
    width = 10,
    height = 7
  )

  # --- family summary + prevalence ---
  fam_sum <- prop_long %>%
    group_by(Group, family) %>%
    summarise(
      mean_prop = mean(proportion, na.rm = TRUE),
      median_prop = median(proportion, na.rm = TRUE),
      sd_prop = sd(proportion, na.rm = TRUE),
      n_samples = n(),
      .groups = "drop"
    ) %>%
    mutate(
      module = module_annotation(family),
      primary_module = primary_module(family)
    ) %>%
    arrange(Group, primary_module, family)
  write_results(
    fam_sum,
    file.path(tables_dir, "mucin_target_family_summary.tsv")
  )

  prev <- prevalence_summary(count_long, group_levels)
  prev$module <- module_annotation(prev$family)
  prev$primary_module <- primary_module(prev$family)
  write_results(
    prev,
    file.path(tables_dir, "mucin_target_prevalence_summary.tsv")
  )
  plot_prevalence_heatmap_module(
    prev,
    group_levels,
    file.path(output_dir, "figM4_mucin_prevalence_heatmap.png"),
    width = 5,
    height = 9
  )

  write_results(
    prop_long,
    file.path(tables_dir, "mucin_target_proportion_long.tsv")
  )
  write_results(
    count_long,
    file.path(tables_dir, "mucin_target_present_count_long.tsv")
  )

  cat("  Finished:", title_tag, "\n")
}

run_mucin_pairwise <- function(
  prop_cov,
  count_wide,
  group_levels,
  output_dir,
  title_tag
) {
  dir.create(file.path(output_dir, "tables"), recursive = TRUE, showWarnings = FALSE)
  tables_dir <- file.path(output_dir, "tables")

  cat("\nTargeted pairwise processing:", title_tag, "->", output_dir, "\n")

  tfams <- target_families(prop_cov)
  if (length(tfams) == 0) {
    cat("  No target families available. Skipping pairwise.\n")
    return(invisible(NULL))
  }

  prop_r <- restrict_to_targets(prop_cov, tfams)
  count_r <- restrict_to_targets(count_wide, intersect(tfams, colnames(count_wide)))
  prop_long <- make_long(prop_r, "proportion")

  pairwise <- pairwise_groups(prop_long, group_levels)
  if (nrow(pairwise) > 0) {
    pairwise$module <- module_annotation(pairwise$family)
    pairwise$primary_module <- primary_module(pairwise$family)
    write_results(
      pairwise,
      file.path(tables_dir, "mucin_family_pairwise_results.tsv")
    )
    write_pairwise_matrices(pairwise, tables_dir)

    comparison_summary <- pairwise %>%
      group_by(comparison, group1, group2, n1, n2) %>%
      summarise(
        n_families = n(),
        n_significant_FDR_0.05 = sum(FDR < 0.05, na.rm = TRUE),
        n_upregulated_in_group1 = sum(log2FC > 0 & FDR < 0.05, na.rm = TRUE),
        n_downregulated_in_group1 = sum(log2FC < 0 & FDR < 0.05, na.rm = TRUE),
        .groups = "drop"
      ) %>%
      arrange(comparison)
    write_results(
      comparison_summary,
      file.path(tables_dir, "mucin_family_pairwise_comparison_summary.tsv")
    )

    save_pairwise_heatmap(
      pairwise,
      file.path(output_dir, "figS2_mucin_pairwise_differential_heatmap.png"),
      width = 6.5,
      height = 9
    )

    comparisons <- unique(pairwise$comparison)
    for (cc in comparisons) {
      cc_dat <- pairwise %>% filter(comparison == cc)
      prefix <- paste0(
        "figS1_mucin_pairwise_volcano_",
        gsub("[^A-Za-z0-9_]+", "_", cc)
      )
      save_figure(
        plot_volcano_module(
          cc_dat,
          paste(title_tag, "Targeted CAZyme Pairwise Volcano:", cc),
          subtitle = "Wilcoxon rank-sum test with BH FDR; effect size = median1 - median2",
          x_label = "Effect size (median group1 - median group2)"
        ),
        prefix,
        output_dir,
        width = 6,
        height = 5.5
      )
    }
  }

  # --- module-level pairwise ---
  mod_agg <- module_aggregate(prop_cov, count_wide)
  mod_agg$Group <- factor(mod_agg$Group, levels = group_levels)
  mod_pair <- module_pairwise(mod_agg)
  if (nrow(mod_pair) > 0) {
    write_results(
      mod_pair,
      file.path(tables_dir, "mucin_module_pairwise_results.tsv")
    )
  }

  cat("  Finished pairwise:", title_tag, "\n")
}

5.5 Interpretation

  1. No mucin / glycan module is significant; mucin-degradation capacity is stable across recurrence status and sampling time.
  2. The strongest trend is plant polysaccharide degradation (p = 0.178), driven mainly by GH26 and consistent with the dbCAN3 per-family result.
  3. Module-level testing reduces the burden from ~300 families to 4 tests, but effect sizes are too small to reach significance at n = 236.

6. Overall interpretation

  1. All three phenotype-prediction tools agree: no predicted phenotype differs significantly between the four adenoma follow-up groups in per-feature or multivariate tests.
  2. Top raw-p candidates are biologically coherent but not significant. They point to carbohydrate metabolism, polysaccharide transport, and plant/mucin glycan degradation, but remain hypothesis-generating leads.
  3. Multivariate separation is absent. PERMANOVA R2 is about 0.012-0.015 with P = 0.20-0.55; betadisper is non-significant except for 6-group Traitar (P = 0.043, a dispersion rather than location effect).
  4. Implications. At n = 236 (4-group) the cohort is underpowered after correction for 60-300 tests. The targeted module approach is the right scale and shows the expected direction without reaching significance. Next steps: increase sample size, focus on pre-specified modules, and integrate with the paired delta analysis.
